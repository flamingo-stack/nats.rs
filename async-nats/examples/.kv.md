Brief description: A demonstration of NATS JetStream Key-Value (KV) store operations using `async_nats`, covering bucket creation, CRUD operations, optimistic concurrency control, stream abstraction, and real-time change watching.

## Key Components

- **`create_key_value`** — Creates a named KV bucket (`profiles`) backed by a JetStream stream with the `KV_` prefix convention
- **`put` / `entry`** — Basic write and read operations with revision tracking per entry
- **`update`** — Conditional write enforcing optimistic concurrency control (OCC) by requiring a matching revision number
- **`keys`** — Iterates and collects all keys in the bucket
- **`delete`** — Deletes a key, emitting a `KV-Operation: DEL` header-tagged message on the underlying stream
- **`watch`** — Returns a `KeyWatcher` stream that yields `Entry` values for real-time change tracking, supporting wildcard patterns (e.g., `sue.*`)
- **Stream access** — Direct consumer access to the underlying `KV_profiles` stream for raw message inspection

## Usage Example

```rust
use async_nats::jetstream;
use futures_util::TryStreamExt;

#[tokio::main]
async fn main() -> Result<(), async_nats::Error> {
    let client = async_nats::connect("nats://localhost:4222").await?;
    let jetstream = jetstream::new(client);

    // Create a KV bucket
    let kv = jetstream
        .create_key_value(async_nats::jetstream::kv::Config {
            bucket: "profiles".to_string(),
            ..Default::default()
        })
        .await?;

    // Put and retrieve a value with revision tracking
    kv.put("sue.color", "blue".into()).await?;
    if let Some(entry) = kv.entry("sue.color").await? {
        println!("rev {}: {}", entry.revision, std::str::from_utf8(&entry.value)?);
    }

    // Conditional update (OCC) — only succeeds if revision matches
    kv.update("sue.color", "red".into(), 2).await?;

    // Watch for changes on a wildcard key pattern
    let mut watch = kv.watch("sue.*").await?;
    kv.put("sue.food", "pizza".into()).await?;
    if let Some(Ok(entry)) = watch.next().await {
        println!("changed: {} -> {:?}", entry.key, entry.operation);
    }

    Ok(())
}
```
