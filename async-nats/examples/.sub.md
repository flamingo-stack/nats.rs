A minimal NATS subscriber example demonstrating how to connect to a NATS server and consume messages from a subject using the async NATS client.

## Key Components

- **`main`** — Async entry point that connects to a local NATS server, subscribes to the `"foo"` subject, and prints each received message until the subscription ends.

## Usage Example

```rust
#[tokio::main]
async fn main() -> Result<(), async_nats::Error> {
    // Connect to a local NATS server
    let client = async_nats::connect("nats://localhost:4222").await?;

    // Subscribe to a subject
    let mut subscriber = client.subscribe("foo").await.unwrap();

    // Consume messages as an async stream
    while let Some(message) = subscriber.next().await {
        println!("Received message {message:?}");
    }

    Ok(())
}
```

## Notes

- Requires a running NATS server at `nats://localhost:4222`.
- Uses `futures_util::StreamExt` to iterate over the subscriber as an async stream.
- Tracks elapsed time from subscription start to stream completion via `std::time::Instant`.
- The message loop exits when the subscription is closed or the connection drops.
