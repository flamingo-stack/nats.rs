Demonstrates concurrent NATS message processing using `for_each_concurrent`, allowing multiple messages to be handled simultaneously without blocking on slow per-message operations.

## Key Components

- **`main`** — Async entry point that connects to NATS, subscribes to `greet.*`, publishes 50 messages, then processes them concurrently with a parallelism limit of 25.
- **`subscription.take(50)`** — Bounds the subscriber to consume exactly 50 messages before completing the stream.
- **`for_each_concurrent(25, ...)`** — Processes up to 25 messages in parallel; each handler simulates variable latency (0–500ms random sleep) without blocking receipt of the next message.

## Usage Example

```rust
// Set NATS server URL via environment variable (optional)
// export NATS_URL=nats://localhost:4222

let client = async_nats::connect("nats://localhost:4222").await?;

let subscription = client.subscribe("greet.*").await?.take(50);

for i in 0..50 {
    client.publish("greet.joe", format!("hello {i}").into()).await?;
}
client.flush().await?;

// Process up to 25 messages concurrently
subscription
    .for_each_concurrent(25, |message| async move {
        // Simulate per-message work without blocking other consumers
        println!("{:?}", std::str::from_utf8(&message.payload).unwrap());
    })
    .await;
```
