Demonstrates JSON serialization and deserialization of structured messages over NATS using `serde_json`, publishing a typed payload and consuming it from a subscription.

## Key Components

- **`Payload`** — A sample struct deriving `Serialize`/`Deserialize` with `foo: String` and `bar: u8` fields, used to demonstrate typed message handling.
- **`main`** — Async entry point that connects to NATS, publishes a JSON-serialized `Payload` to the `"foo"` subject, and deserializes the received message back into a `Payload`.

## Usage Example

```rust
use serde::{Deserialize, Serialize};
use serde_json::json;

#[derive(Serialize, Deserialize)]
struct Payload {
    foo: String,
    bar: u8,
}

// Serialize to bytes for publishing
let payload = Payload { foo: "bar".to_string(), bar: 27 };
let bytes = serde_json::to_vec(&json!(payload))?;
client.publish("foo", bytes.into()).await?;

// Deserialize on receipt
if let Ok(payload) = serde_json::from_slice::<Payload>(&message.payload) {
    println!("foo={:?} bar={:?}", payload.foo, payload.bar);
}
```

Set `NATS_URL` to override the default server address:

```bash
NATS_URL=nats://myserver:4222 cargo run
```
