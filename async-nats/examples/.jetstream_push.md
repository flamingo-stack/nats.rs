A runnable example demonstrating JetStream push consumer usage with async-nats: creates a stream, publishes messages, and consumes them via a push-based consumer with acknowledgements.

## Key Components

| Component | Description |
|---|---|
| `PushConsumer` | JetStream push consumer that delivers messages to a client-specified inbox subject |
| `jetstream::new()` | Creates a JetStream context from an existing NATS client connection |
| `create_stream()` | Creates an `EVENTS` stream subscribed to the `events.>` wildcard subject |
| `create_consumer()` | Chains directly off the stream to create a push consumer with a dedicated inbox |
| `consumer.messages()` | Returns an async stream iterator over incoming messages |
| `message.ack()` | Sends a JetStream acknowledgement to prevent redelivery |

## Usage Example

```rust
// Connect and set up JetStream
let client = async_nats::connect("nats://localhost:4222").await?;
let jetstream = jetstream::new(client);
let inbox = client.new_inbox();

// Create stream + push consumer in one chain
let consumer: PushConsumer = jetstream
    .create_stream(jetstream::stream::Config {
        name: "EVENTS".to_string(),
        subjects: vec!["events.>".to_string()],
        ..Default::default()
    })
    .await?
    .create_consumer(jetstream::consumer::push::Config {
        deliver_subject: inbox.clone(),
        inactive_threshold: Duration::from_secs(60),
        ..Default::default()
    })
    .await?;

// Consume up to 10 messages
let mut messages = consumer.messages().await?.take(10);
while let Some(message) = messages.next().await {
    let message = message?;
    message.ack().await?;
}
```

Set `NATS_URL` to override the default `nats://localhost:4222` connection target.
