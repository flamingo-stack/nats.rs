Publishes 10 million NATS messages to a single subject as a performance benchmark, measuring total throughput time.

## Key Components

- **`main`** — Async entry point that connects to a local NATS server, publishes 10M messages, flushes the connection, and prints elapsed time.

## Usage Example

```bash
# Start a local NATS server first
nats-server

# Run the benchmark
cargo run --example pub
```

```rust
use async_nats::{connect, Subject};
use bytes::Bytes;
use std::time::Instant;

let client = connect("nats://localhost:4222").await?;
let now = Instant::now();

for _ in 0..10_000_000 {
    client.publish(Subject::from("foo"), Bytes::from("bar")).await?;
}
client.flush().await?;

println!("published in {:?}", now.elapsed());
```

## Notes

- `client.flush()` is called after the loop to ensure all buffered messages are fully sent before recording elapsed time.
- `Subject` and `Bytes` are cloned per iteration to satisfy ownership; both types use cheap reference-counted cloning.
- The server URL `nats://localhost:4222` is hardcoded — adjust for non-local targets.
