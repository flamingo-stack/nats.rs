Integration test suite for JetStream functionality in the `async_nats` client, covering stream creation, publishing, consuming, and account management operations.

## Key Components

- **`AccountInfo`** — Public struct representing JetStream account usage stats (memory, storage, streams, consumers)
- **`jetstream` module** — Inner test module containing all `#[tokio::test]` async integration tests

### Test Coverage

| Test | Description |
|------|-------------|
| `query_account_requests` | Verifies account query tracking increments correctly |
| `publish_with_headers` | Tests publishing with custom `HeaderMap` headers |
| `publish_async` | Validates async publish ACK futures for valid/invalid subjects |
| `send_publish` | Tests `Publish::build()` builder with dedup, expected sequence, last message ID, and stream name guards |
| `request` / `request_ok` / `request_err` | Covers JetStream API request/response deserialization |
| `create_stream` | Tests stream creation from string name and `stream::Config` struct |
| `create_stream_with_replicas` | Cluster-only test for replicated streams (non-Windows) |

## Usage Example

```rust
// Typical pattern used throughout the tests
let server = nats_server::run_server("tests/configs/jetstream.conf");
let client = async_nats::connect(server.client_url()).await.unwrap();
let context = async_nats::jetstream::new(client);

// Create a stream
context.create_stream(stream::Config {
    name: "TEST".into(),
    subjects: vec!["foo".into()],
    ..Default::default()
}).await.unwrap();

// Publish with dedup guard
context
    .send_publish("foo", Publish::build().message_id("UUID"))
    .await.unwrap()
    .await.unwrap();
```

## Notes

- Tests require a running NATS server with JetStream enabled via `tests/configs/jetstream.conf`
- Some tests are gated behind feature flags: `server_2_10` and `server_2_11`
- The `request_no_responders` test is `#[ignore]`d and connects to a hardcoded local server
- Source: [`tests/jetstream_tests.rs`](https://github.com/flamingo-stack/nats.rs/blob/main/tests/jetstream_tests.rs)
