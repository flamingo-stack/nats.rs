Integration test suite for the NATS JetStream Key-Value (KV) store, validating bucket management, CRUD operations, history, watchers, and multi-replicated cluster behavior.

## Key Components

| Test | Description |
|------|-------------|
| `create_bucket` | Verifies bucket creation with correct stream name, discard policy, and direct-access config |
| `create` | Tests idempotent create semantics (fail on duplicate, succeed after delete/purge) |
| `put` / `get` | Basic read/write operations with value overwrite verification |
| `entry` / `update` | Retrieves full `Entry` metadata; CAS update with revision tracking |
| `delete` / `delete_expect_revision` | Soft-delete semantics and revision-gated deletes |
| `history` | Streams all historical operations for a key |
| `watch` / `watch_all` | Async watchers for key-specific and wildcard change streams |
| `purge` | Hard-removes all key history |
| `republish` / `mirror` / `sourced_kv` | Cross-bucket replication, mirroring, and JetStream sourcing |
| `update_bucket` | Validates `UpdateKeyValueErrorKind` error variants on invalid config updates |

## Usage Example

```rust
// Connect and create a KV bucket
let client = async_nats::connect("nats://localhost:4222").await?;
let context = async_nats::jetstream::new(client);

let kv = context
    .create_key_value(async_nats::jetstream::kv::Config {
        bucket: "my_bucket".into(),
        history: 10,
        storage: StorageType::File,
        num_replicas: 1,
        ..Default::default()
    })
    .await?;

// Put, get, and delete
let rev = kv.put("key", Bytes::from("value")).await?;
let val = kv.get("key").await?;

// CAS update
kv.update("key", Bytes::from("new_value"), rev).await?;

// Watch for changes
let mut watcher = kv.watch("key").await?;
while let Some(entry) = watcher.next().await {
    println!("{:?}", entry?);
}
```
