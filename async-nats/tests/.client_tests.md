Integration tests for the `async_nats` client covering core pub/sub, request/reply, subscription lifecycle, reconnection behavior, and connection options.

## Key Components

| Test | Description |
|------|-------------|
| `force_reconnect` | Verifies disconnect/reconnect events fire correctly and subscriptions survive reconnection |
| `basic_pub_sub` | Publishes 10 messages and asserts all are received by a subscriber |
| `queue_sub` | Validates queue group distribution across multiple subscribers |
| `cloned_client` | Ensures a cloned client shares the same connection and can publish/receive |
| `publish_with_headers` | Tests `HPUB` with single and multi-value headers |
| `publish_request` | Low-level reply-to pattern using `new_inbox` and `publish_with_reply` |
| `request` | High-level `client.request()` round-trip |
| `request_timeout` | Asserts `RequestErrorKind::TimedOut` when no responder replies |
| `request_no_responders` | Asserts `RequestErrorKind::NoResponders` when no subscriber exists |
| `request_builder` | Uses `Request::new().inbox(...)` to customise the reply subject |
| `unsubscribe` | Confirms clean unsubscribe and continued client usability |
| `unsubscribe_after` | Auto-unsubscribes after N messages via `unsubscribe_after(n)` |

## Usage Example

```rust
// Run a specific test against a local NATS server
#[tokio::test]
async fn basic_pub_sub() {
    let server = nats_server::run_basic_server();
    let client = async_nats::connect(server.client_url()).await.unwrap();

    let mut subscriber = client.subscribe("foo").await.unwrap();
    client.publish("foo", "data".into()).await.unwrap();
    client.flush().await.unwrap();

    assert!(subscriber.next().await.is_some());
}
```

These tests require a running `nats_server` test helper. See the full suite at [`async-nats/tests/client_tests.rs`](https://github.com/flamingo-stack/nats.rs/blob/main/async-nats/tests/client_tests.rs).
