Integration test suite for the `async_nats` service feature, validating service lifecycle, configuration, endpoint groups, request/response handling, and queue group behavior.

## Key Components

| Test | Description |
|------|-------------|
| `service_config_validations` | Asserts that invalid semver versions and malformed service names (dots, spaces) are rejected with `InvalidInput` errors |
| `options` | Verifies service-level and endpoint-level metadata propagation via `$SRV.INFO` |
| `ping` | Confirms multiple registered services each respond to a `$SRV.PING` broadcast |
| `groups` | Tests grouped endpoint routing (e.g., `v2.products` via `service.group("v2")`) |
| `requests` | End-to-end request handling including stats tracking, error responses with `503` codes, and service shutdown behavior |
| `custom_queue_groups` | Validates that custom queue group names are respected and surfaced in `$SRV.STATS` |

## Usage Example

```rust
// Register a service and handle endpoint requests
let service = client
    .add_service(async_nats::service::Config {
        name: "serviceA".to_string(),
        version: "1.0.0".to_string(),
        description: None,
        stats_handler: None,
        metadata: None,
        queue_group: None,
    })
    .await
    .unwrap();

let mut endpoint = service.endpoint("products").await.unwrap();
while let Some(request) = endpoint.next().await {
    request.respond(Ok("data".into())).await.unwrap();
}

// Stop the service when done
service.stop().await.unwrap();
```

All tests are gated behind the `service` feature flag (`#[cfg(feature = "service")]`).
