Integration test suite for NATS JetStream Object Store functionality, validating core operations including put/get, deletion, watching, linking, metadata handling, and bucket sealing.

## Key Components

| Test | Description |
|------|-------------|
| `get_and_put` | Validates storing and retrieving objects with SHA-256 digest verification, links, and custom chunk sizing |
| `purge_existing_object_on_put` | Ensures old NUID-tagged chunks are purged when an object is overwritten |
| `watch` | Verifies real-time object change notifications (put/delete events) |
| `watch_with_history` | Tests `LastPerSubject` delivery policy, replaying latest version per key before live updates |
| `info` | Confirms object metadata, headers, size, bucket name, and modification timestamps |
| `delete` | Validates soft-deletion behavior (size zeroed, `deleted` flag set, `get` returns `NotFound`) |
| `seal` | (Truncated) Tests bucket sealing to prevent further writes |

## Usage Example

```rust
// Create a JetStream object store bucket and round-trip an object
let server = nats_server::run_server("tests/configs/jetstream.conf");
let client = async_nats::connect(server.client_url()).await.unwrap();
let jetstream = async_nats::jetstream::new(client);

let bucket = jetstream
    .create_object_store(async_nats::jetstream::object_store::Config {
        bucket: "my-bucket".to_string(),
        ..Default::default()
    })
    .await
    .unwrap();

// Store an object
bucket.put("my-key", &mut b"hello world".as_slice()).await.unwrap();

// Retrieve and read it back
let mut object = bucket.get("my-key").await.unwrap();
let mut contents = Vec::new();
object.read_to_end(&mut contents).await.unwrap();

// Watch for changes
let mut watcher = bucket.watch().await.unwrap();
while let Some(Ok(event)) = watcher.next().await {
    println!("Changed: {} (deleted={})", event.name, event.deleted);
}
```

## Notes

- Tests require a running NATS server configured with JetStream (`tests/configs/jetstream.conf`)
- SHA-256 digests are verified using `ring::digest` and base64 URL-safe encoding
- Object links are stored as metadata references within the same bucket
- Source: [`async-nats/tests/object_store.rs`](https://github.com/flamingo-stack/nats.rs/blob/main/async-nats/tests/object_store.rs)
