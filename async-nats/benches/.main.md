Entry point for the benchmark suite that wires together all benchmark groups using the [Criterion](https://github.com/bheisler/criterion.rs) framework.

## Key Components

- **`core_nats` module** — Imports benchmark group definitions from [`core_nats.rs`](https://github.com/flamingo-stack/nats.rs/blob/main/benches/core_nats.rs)
- **`jetstream` module** — Imports benchmark group definitions from [`jetstream.rs`](https://github.com/flamingo-stack/nats.rs/blob/main/benches/jetstream.rs)
- **`criterion_main!`** — Macro that registers and runs both `core_nats::core_nats` and `jetstream::jetstream` benchmark groups as a single executable

## Usage Example

Run all benchmarks from the repository root:

```bash
cargo bench
```

Run only a specific benchmark group by name filter:

```bash
# Run only core NATS benchmarks
cargo bench -- core_nats

# Run only JetStream benchmarks
cargo bench -- jetstream
```

Results are written to `target/criterion/` and can be compared across runs to detect performance regressions.

## Notes

- Adding a new benchmark group requires declaring a new `mod` here and appending it to the `criterion_main!` invocation.
- See [`core_nats.rs`](https://github.com/flamingo-stack/nats.rs/blob/main/benches/core_nats.rs) and [`jetstream.rs`](https://github.com/flamingo-stack/nats.rs/blob/main/benches/jetstream.rs) for the individual benchmark definitions.
