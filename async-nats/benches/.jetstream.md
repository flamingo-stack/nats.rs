Criterion benchmark suite for measuring NATS JetStream publish performance, covering both synchronous (awaited-per-message) and asynchronous (pipelined) publish strategies across multiple message sizes.

## Key Components

| Item | Description |
|------|-------------|
| `jetstream_publish_sync` | Benchmark group measuring throughput and message rate for synchronous JetStream publishes (waits for each ack before sending the next) |
| `jetstream_publish_async` | Benchmark group measuring throughput and message rate for async/pipelined JetStream publishes (sends all messages then collects acks via a channel) |
| `publish_sync_batch` | Helper that publishes `amount` messages sequentially, awaiting each `PublishAckFuture` inline |
| `publish_async_batch` | Helper that pipelines publishes by pushing `PublishAckFuture` values into an `mpsc` channel consumed by a background task |
| `criterion_group!` | Registers both benchmark functions under the `jetstream` group |

**Message sizes tested:** 32 B, 1 KB, 8 KB — 50,000 messages per iteration.

## Usage Example

Run the benchmarks from the repository root:

```bash
# Run all JetStream benchmarks
cargo bench --bench jetstream

# Run only the async publish benchmarks
cargo bench --bench jetstream -- "jetstream async publish"

# Run only the sync throughput benchmarks
cargo bench --bench jetstream -- "jetstream::sync_publish_throughput"
```

Results are saved to `target/criterion/`. Each group reports two metrics:

- **Throughput** — bytes/second (`Throughput::Bytes`)
- **Message rate** — messages/second (`Throughput::Elements`)

> **Note:** Requires a running NATS server configured via `tests/configs/jetstream.conf`. The benchmark creates and purges a stream named `bench` on the `bench` subject before each sample.
