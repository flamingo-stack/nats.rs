Manages NATS server connections, handling initial connection setup, reconnection logic, server discovery, and authentication for the async NATS client.

## Key Components

### `ConnectorOptions`
Configuration struct holding TLS settings, authentication credentials, connection timeouts, reconnect behavior, and callback functions for dynamic auth.

### `Connector`
Core struct maintaining the server list with connection attempt counts, managing reconnection state, and coordinating connection establishment.

### `reconnect_delay_callback_default`
Default exponential backoff function — returns `0ms` for the first attempt, then caps at `4s` using `2^(attempts-1)` milliseconds.

### Key Methods

| Method | Description |
|--------|-------------|
| `Connector::new()` | Initializes connector from server addresses and options |
| `connect()` | Loops until a successful connection is established, handling auth errors and max reconnects |
| `try_connect()` | Single-pass attempt across all known servers with backoff delay |
| `handle_auth_error()` | Invokes `auth_url_callback` to fetch a new server URL on auth failures |
| `is_auth_error()` | Detects HTTP 401-style error strings |

## Usage Example

```rust
let options = ConnectorOptions {
    tls_required: false,
    auth: Auth::default(),
    connection_timeout: Duration::from_secs(5),
    max_reconnects: Some(10),
    reconnect_delay_callback: Box::new(reconnect_delay_callback_default),
    // ...other fields
};

let mut connector = Connector::new(
    "nats://localhost:4222",
    options,
    events_tx,
    state_tx,
    max_payload,
    connect_stats,
)?;

let (server_info, connection) = connector.connect().await?;
```
