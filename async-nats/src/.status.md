Defines the `StatusCode` type for NATS protocol status codes, providing parsing, validation, and classification of 3-digit numeric status values in the range 100–999.

## Key Components

- **`StatusCode`** — Core newtype wrapping `NonZeroU16`, representing a NATS status code. Implements `Clone`, `Copy`, `PartialEq`, `Ord`, `Hash`, `Serialize`, and `Deserialize`.
- **`InvalidStatusCode`** — Error type returned when parsing or converting an out-of-range or malformed value.
- **Status Constants** — Predefined codes:
  - `IDLE_HEARTBEAT` (100)
  - `OK` (200)
  - `NOT_FOUND` (404)
  - `TIMEOUT` (408)
  - `REQUEST_TERMINATED` (409)
  - `NO_RESPONDERS` (503)
- **Classification methods** — `is_informational()`, `is_success()`, `is_redirection()`, `is_client_error()`, `is_server_error()`
- **Conversions** — `From`/`TryFrom` impls for `u16`, `&str`, `&[u8]`; `FromStr` support

## Usage Example

```rust
use async_nats::StatusCode;

// Use a predefined constant
assert_eq!(StatusCode::OK.as_u16(), 200);
assert!(StatusCode::OK.is_success());

// Parse from a u16
let code = StatusCode::from_u16(404).unwrap();
assert_eq!(code, StatusCode::NOT_FOUND);
assert!(code.is_client_error());

// Parse from a string
let code: StatusCode = "503".parse().unwrap();
assert_eq!(code, StatusCode::NO_RESPONDERS);
assert!(code.is_server_error());

// Out-of-range values return an error
assert!(StatusCode::from_u16(99).is_err());
assert!(StatusCode::from_u16(1000).is_err());
```
