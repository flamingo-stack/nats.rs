A Rust asynchronous client library for the NATS.io messaging ecosystem, providing core types, connection management, and re-exports for pub/sub, JetStream, key-value, object store, and service APIs.

## Key Components

| Item | Description |
|------|-------------|
| `Error` | Type alias for `Box<dyn std::error::Error + Send + Sync + 'static>` |
| `Client` | Primary async NATS client (re-exported from `client`) |
| `ConnectOptions` | Builder for configuring NATS connections |
| `ServerInfo` | Deserialized server handshake metadata (version, TLS, JetStream, cluster, etc.) |
| `PublishMessage` | Represents a message being published (subject, payload, reply, headers) |
| `Command` | Internal enum of all operations a `Client` can dispatch |
| `ClientOp` | Internal enum of wire-level client protocol actions |
| `ServerOp` | Internal enum of parsed server protocol messages |
| `HeaderMap` / `HeaderName` / `HeaderValue` | NATS message header types |
| `Subject` | Strongly-typed NATS subject |
| `StatusCode` | NATS status codes |
| `rustls` | Re-exported for manual TLS client configuration |
| `jetstream` | JetStream API module (streams, consumers, KV, object store) |
| `service` | Service API module (feature-gated via `service`) |

## Usage Example

```rust
use bytes::Bytes;
use futures_util::StreamExt;

#[tokio::main]
async fn main() -> Result<(), async_nats::Error> {
    // Connect to NATS
    let client = async_nats::connect("demo.nats.io").await?;

    // Subscribe
    let mut subscriber = client.subscribe("messages").await?;

    // Publish
    client.publish("messages", Bytes::from("hello")).await?;
    client.flush().await?;

    // JetStream
    let js = async_nats::jetstream::new(client.clone());
    js.publish("events", "data".into()).await?;

    // Receive
    if let Some(msg) = subscriber.next().await {
        println!("Got: {:?}", msg);
    }

    Ok(())
}
```
