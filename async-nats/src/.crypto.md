Provides a thin abstraction over SHA-256 hashing, selecting either `aws-lc-rs` or `ring` as the cryptographic backend at compile time via feature flags.

## Key Components

### `Sha256`
An incremental SHA-256 hasher wrapping the backend's digest `Context`.

| Method | Description |
|--------|-------------|
| `Sha256::new()` | Initializes a new SHA-256 digest context |
| `update(&mut self, chunk: &[u8])` | Feeds a byte slice into the running hash |
| `finish(self) -> [u8; 32]` | Finalizes the digest and returns the 32-byte hash |

### Feature Flags

| Flag | Backend |
|------|---------|
| `aws-lc-rs` | Uses `aws-lc-rs` (FIPS-compatible) |
| `ring` | Uses `ring` |

> A `compile_error!` is emitted if neither feature is enabled.

## Usage Example

```rust
use crate::crypto::Sha256;

let mut hasher = Sha256::new();
hasher.update(b"hello ");
hasher.update(b"world");
let digest: [u8; 32] = hasher.finish();
```

## Notes

- This module is `pub(crate)` — it is an internal utility not exposed in the public API.
- Swapping between backends requires only a feature flag change; no call-site changes are needed.
- At least one of `aws-lc-rs` or `ring` must be enabled, enforced at compile time.
