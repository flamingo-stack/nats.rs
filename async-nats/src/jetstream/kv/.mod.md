A Key-Value store module built on top of JetStream, providing NATS-backed storage with support for put, get, create, update, delete, and purge operations with history tracking.

## Key Components

- **`Store`** — Primary handle for interacting with a KV bucket; wraps a JetStream `Stream` and exposes all KV operations
- **`Config`** — Configuration struct for creating KV buckets (bucket name, history, TTL, storage type, replication, mirroring, etc.)
- **`Operation`** — Enum representing the type of a KV entry: `Put`, `Delete`, or `Purge`
- **`bucket` (submodule)** — Contains `Status` and related bucket-level types
- **`is_valid_bucket_name` / `is_valid_key`** — Validation helpers enforcing NATS KV naming rules via compiled regexes
- **`ParseOperationError`** — Error type for invalid `KV-Operation` header values

## Usage Example

```rust
use async_nats::jetstream::kv::Config;

#[tokio::main]
async fn main() -> Result<(), async_nats::Error> {
    let client = async_nats::connect("demo.nats.io:4222").await?;
    let jetstream = async_nats::jetstream::new(client);

    // Create a KV bucket with 10 history entries
    let kv = jetstream
        .create_key_value(Config {
            bucket: "my-bucket".to_string(),
            history: 10,
            ..Default::default()
        })
        .await?;

    // Put a value
    kv.put("my-key", "hello".into()).await?;

    // Create only if absent
    kv.create("new-key", "value".into()).await?;

    // Create with per-key TTL (requires server_2_11 feature)
    // kv.create_with_ttl("ttl-key", "value".into(), Duration::from_secs(30)).await?;

    // Check bucket status
    let status = kv.status().await?;
    println!("{:?}", status);

    Ok(())
}
```

## Notes

- Valid bucket names match `[a-zA-Z0-9_-]+`; valid keys match `[-/_=.a-zA-Z0-9]+` and cannot start/end with `.`
- `MAX_HISTORY` is capped at 64
- `Config.compression` requires the `server_2_10` feature flag; `Config.limit_markers` requires `server_2_11`
