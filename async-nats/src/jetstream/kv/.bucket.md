Represents status information for a NATS JetStream Key-Value store bucket, exposing metadata about message retention and configuration.

## Key Components

### `Status`

A struct wrapping JetStream stream `Info` alongside a bucket name string, providing accessor methods for common KV bucket metadata.

| Method | Return Type | Description |
|---|---|---|
| `bucket()` | `&str` | The bucket's name |
| `values()` | `u64` | Total message count, including historical values |
| `history()` | `i64` | Max historical values retained per key |
| `max_age()` | `Duration` | How long values are retained in the bucket |

## Usage Example

```rust
use nats::jetstream::kv;

let client = nats::connect("nats://localhost:4222")?;
let context = nats::jetstream::new(client);

let kv = context.create_key_value(&kv::Config {
    bucket: "my-bucket".to_string(),
    history: 5,
    max_age: std::time::Duration::from_secs(3600),
    ..Default::default()
})?;

let status: kv::Status = kv.status()?;

println!("Bucket:  {}", status.bucket());
println!("Values:  {}", status.values());
println!("History: {}", status.history());
println!("Max Age: {:?}", status.max_age());
```

## Notes

- `values()` reflects the total message count across all keys and revisions, not just the latest values.
- `history()` maps to `max_messages_per_subject` on the underlying JetStream stream config.
- `max_age()` is sourced directly from the stream's `max_age` configuration field.
