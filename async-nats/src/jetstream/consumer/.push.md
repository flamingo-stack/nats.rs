Push consumer implementation for NATS JetStream, providing server-pushed message delivery to subscribers with support for durable/ephemeral consumers, heartbeat monitoring, and flow control.

## Key Components

- **`Consumer<Config>::messages()`** — Async method that subscribes to the consumer's deliver subject (or queue group) and returns a `Messages` stream
- **`Messages`** — A `futures_util::Stream` implementation yielding `Result<Message, MessagesError>`, handling idle heartbeats, status messages, and flow control signals
- **`Config`** — Serializable configuration struct for push consumers, covering delivery policy, ACK behavior, rate limiting, filtering, heartbeats, and server-version-gated features (`server_2_10`, `server_2_11`)

### Notable Config Fields

| Field | Purpose |
|---|---|
| `deliver_subject` | NATS subject messages are pushed to |
| `durable_name` | Makes the consumer durable (server tracks progress) |
| `deliver_group` | Queue group for load-balanced delivery |
| `idle_heartbeat` | Triggers `MissingHeartbeat` error if no heartbeat received within 2× interval |
| `backoff` | Custom redelivery backoff schedule |
| `pause_until` | Pause consumer until a deadline (`server_2_11` only) |

## Usage Example

```rust
use async_nats::jetstream::consumer::PushConsumer;
use futures_util::StreamExt;

let client = async_nats::connect("localhost:4222").await?;
let jetstream = async_nats::jetstream::new(client);

let stream = jetstream
    .get_or_create_stream(async_nats::jetstream::stream::Config {
        name: "events".to_string(),
        ..Default::default()
    })
    .await?;

let consumer: PushConsumer = stream
    .get_or_create_consumer(
        "consumer",
        async_nats::jetstream::consumer::push::Config {
            durable_name: Some("consumer".to_string()),
            deliver_subject: "deliver".to_string(),
            ..Default::default()
        },
    )
    .await?;

let mut messages = consumer.messages().await?;
while let Some(Ok(msg)) = messages.next().await {
    println!("received: {:?}", msg);
    msg.ack().await?;
}
```
