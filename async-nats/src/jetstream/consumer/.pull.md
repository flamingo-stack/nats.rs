Implements JetStream pull consumer message retrieval for NATS, providing multiple strategies for fetching messages in batches or continuous streams with configurable timeouts, heartbeats, and byte limits.

## Key Components

- **`Consumer<Config>::messages()`** — Returns a continuous `Stream` with default batch settings (200 messages, 30s expiry, 15s heartbeat)
- **`Consumer<Config>::stream()`** — Returns a `StreamBuilder` for customizing stream parameters
- **`Consumer<Config>::fetch()`** — Returns a `FetchBuilder` for one-shot fetches that drain available messages
- **`Consumer<Config>::batch()`** — Returns a `BatchBuilder` for time-bounded batch requests
- **`Consumer<Config>::sequence()`** — Returns a `Sequence` of iterable `Batch` objects for batch-over-batch processing
- **`Consumer<Config>::request_batch()`** — Low-level method to send a pull request to the NATS server
- **`Batch`** — A `futures::Stream` representing a single batch of pulled messages with optional timeout

## Usage Example

```rust
use futures_util::StreamExt;

let client = async_nats::connect("localhost:4222").await?;
let jetstream = async_nats::jetstream::new(client);

let consumer = jetstream
    .get_stream("events").await?
    .get_consumer("pull").await?;

// Continuous stream with defaults
let mut messages = consumer.messages().await?;
while let Some(Ok(msg)) = messages.next().await {
    msg.ack().await?;
}

// Customized stream
let mut messages = consumer
    .stream()
    .max_messages_per_batch(100)
    .max_bytes_per_batch(1024)
    .messages()
    .await?;

// Batch-over-batch sequence
let mut iter = consumer.sequence(50)?.take(10);
while let Ok(Some(mut batch)) = iter.try_next().await {
    while let Ok(Some(msg)) = batch.try_next().await {
        println!("{:?}", msg);
    }
}
```
