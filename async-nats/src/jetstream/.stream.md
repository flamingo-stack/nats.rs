Manages NATS JetStream stream operations, providing a `Stream` handle for inspecting stream info, managing consumers, and directly retrieving messages from stream replicas.

## Key Components

- **`Stream<T>`** — Generic handle to a JetStream stream; `T` defaults to `Info` (cached stream metadata)
- **`Info`** / `StreamInfo` — Cached and live stream configuration and state returned from the server
- **`InfoWithSubjects`** — Async iterator for paginated subject-level message counts
- **`StreamInfoBuilder`** — Builder for customizing stream info requests (filtered subjects, deleted messages)
- **`DirectGetErrorKind`** / **`DirectGetError`** — Typed errors for direct-get operations
- **`DeleteMessageErrorKind`** / **`DeleteMessageError`** — Typed errors for message deletion

## Usage Example

```rust
use async_nats::jetstream;
use futures_util::TryStreamExt;

#[tokio::main]
async fn main() -> Result<(), async_nats::Error> {
    let client = async_nats::connect("localhost:4222").await?;
    let js = jetstream::new(client);

    // Get a stream and refresh its cached info
    let mut stream = js.get_stream("events").await?;
    let info = stream.info().await?;
    println!("Stream state: {:?}", info.state);

    // Direct get — reads from any replica (allow_direct must be true)
    let msg = stream
        .direct_get_next_for_subject("events.data", Some(1))
        .await?;
    println!("Payload: {:?}", msg.payload);

    // Paginate subjects with message counts
    let mut subjects = stream.info_with_subjects("events.>").await?;
    while let Some((subject, count)) = subjects.try_next().await? {
        println!("{subject}: {count} messages");
    }

    Ok(())
}
```
