Provides the NATS JetStream Object Store implementation, enabling large binary object storage and retrieval backed by NATS streams with chunked upload/download, SHA-256 integrity, and link support.

## Key Components

- **`Config`** – Bucket configuration struct (name, max age/bytes, storage type, replicas, compression, placement)
- **`ObjectStore`** – Primary handle for interacting with an object store bucket; wraps a JetStream `Stream`
- **`ObjectMetadata`** / **`ObjectInfo`** – Metadata and full info (size, chunks, digest, timestamps, links) associated with a stored object
- **`Object`** – Implements `tokio::io::AsyncRead` for streaming chunk-by-chunk reads of stored objects
- **`is_valid_bucket_name` / `is_valid_object_name`** – Validation helpers using lazy-compiled regexes
- **`encode_object_name`** – URL-safe base64 encoding for object name subjects

### `ObjectStore` Methods

| Method | Description |
|--------|-------------|
| `put(meta, data)` | Chunks and publishes an `AsyncRead` source; computes SHA-256 digest |
| `get(name)` | Retrieves an `Object` (follows links transparently) |
| `delete(name)` | Marks object deleted and purges its chunks |
| `info(name)` | Fetches the latest `ObjectInfo` metadata message |

## Usage Example

```rust
use tokio::io::AsyncReadExt;

#[tokio::main]
async fn main() -> Result<(), async_nats::Error> {
    let client = async_nats::connect("demo.nats.io").await?;
    let jetstream = async_nats::jetstream::new(client);

    // Upload an object
    let bucket = jetstream.get_object_store("my-bucket").await?;
    let mut file = tokio::fs::File::open("data.bin").await?;
    let info = bucket.put("data.bin", &mut file).await?;
    println!("Stored {} bytes in {} chunks", info.size, info.chunks);

    // Download and read back
    let mut object = bucket.get("data.bin").await?;
    let mut buf = Vec::new();
    object.read_to_end(&mut buf).await?;

    // Delete
    bucket.delete("data.bin").await?;
    Ok(())
}
```
