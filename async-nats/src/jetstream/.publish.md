Represents the acknowledgment response returned by a NATS JetStream server after a message is successfully published to a stream.

## Key Components

### `PublishAck`

A deserialized acknowledgment struct returned from JetStream publish operations. Derives `Debug`, `Default`, `Deserialize`, `Clone`, `PartialEq`, and `Eq`.

| Field | Type | Description |
|-------|------|-------------|
| `stream` | `String` | Name of the stream the message was published to |
| `sequence` | `u64` | Sequence number assigned to the message (deserialized from `"seq"`) |
| `domain` | `String` | JetStream domain the message was published to (defaults to empty string) |
| `duplicate` | `bool` | Whether the server detected the message as a duplicate (defaults to `false`) |

## Usage Example

```rust
use nats::jetstream::PublishAck;

// Typically returned by a JetStream publish call
let client = nats::connect("nats://localhost:4222")?;
let js = nats::jetstream::new(client);

let ack: PublishAck = js.publish("ORDERS.new", "order data")?;

println!("Published to stream: {}", ack.stream);
println!("Assigned sequence:   {}", ack.sequence);

if ack.duplicate {
    println!("Warning: duplicate message detected");
}
```

> **Note:** The `duplicate` field is set by the server when [message deduplication](https://docs.nats.io/jetstream/concepts/deduplication) is enabled on the stream, indicating the message was already received within the deduplication window.
