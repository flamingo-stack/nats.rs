Provides the JetStream `Context` struct and associated methods for managing NATS JetStream operations, including publishing messages, creating/retrieving streams, and querying account information.

## Key Components

- **`Context`** — Core struct holding a `Client`, API prefix, and request timeout. Created via `jetstream::new(client)`.
- **`publish`** — Publishes a payload to a subject and returns a `PublishAckFuture` without blocking on server acknowledgment.
- **`publish_with_headers`** — Publishes a message with custom `HeaderMap` headers attached.
- **`send_publish`** — Lower-level publish using a `Publish` builder for full control over payload, headers, and message ID.
- **`query_account`** — Fetches JetStream account information from the server.
- **`create_stream`** — Creates a new JetStream `Stream` from a `Config`, handling domain/external source resolution automatically.
- **`get_stream_no_info`** — Returns a lightweight `Stream<()>` handle without fetching server-side stream info (efficient for single-operation use cases).
- **`PublishAckFuture`** — A future returned by publish methods that resolves to a `PublishAck` when the server confirms delivery.
- **`Publish`** — A builder type for constructing publish requests with optional headers, message ID, and payload.

## Usage Example

```rust
use async_nats::jetstream::context::Publish;
use async_nats::jetstream::stream::{Config, DiscardPolicy};

#[tokio::main]
async fn main() -> Result<(), async_nats::Error> {
    let client = async_nats::connect("localhost:4222").await?;
    let jetstream = async_nats::jetstream::new(client);

    // Create a stream
    let stream = jetstream
        .create_stream(Config {
            name: "events".to_string(),
            max_messages: 100_000,
            discard: DiscardPolicy::Old,
            ..Default::default()
        })
        .await?;

    // Publish with deferred acknowledgment
    let ack = jetstream
        .send_publish("events", Publish::build().payload("data".into()).message_id("msg-1"))
        .await?;
    ack.await?;

    Ok(())
}
```
