Defines all JetStream API error codes returned by the NATS server, providing a strongly-typed `ErrorCode` wrapper around numeric error identifiers with their associated `Error` trait implementation.

## Key Components

- **`ErrorCode(u64)`** — A newtype wrapper around `u64` representing JetStream server error codes. Derives `Debug`, `PartialEq`, `Eq`, `Clone`, `Copy`, `Deserialize`, and `Serialize`.
- **Associated constants** — Exhaustive set of named `ErrorCode` constants covering all JetStream error categories, including cluster errors, consumer configuration errors, stream lifecycle errors, and resource limit errors.

### Error Code Categories

| Category | Example Constants |
|---|---|
| Cluster | `CLUSTER_NOT_AVAILABLE`, `CLUSTER_NO_PEERS`, `CLUSTER_REQUIRED` |
| Consumer | `CONSUMER_NOT_FOUND`, `CONSUMER_CREATE`, `CONSUMER_INVALID_POLICY` |
| Stream | `STREAM_NOT_FOUND`, `STREAM_NAME_EXIST`, `STREAM_INVALID_CONFIG` |
| Resources | `MEMORY_RESOURCES_EXCEEDED`, `STORAGE_RESOURCES_EXCEEDED` |
| JetStream | `JETSTREAM_NOT_ENABLED`, `JETSTREAM_NOT_ENABLED_FOR_ACCOUNT` |

## Usage Example

```rust
use crate::jetstream::errors::ErrorCode;

// Matching against a server-returned error code
fn handle_error(code: ErrorCode) {
    match code {
        ErrorCode::STREAM_NOT_FOUND => eprintln!("Stream does not exist"),
        ErrorCode::CONSUMER_NOT_FOUND => eprintln!("Consumer does not exist"),
        ErrorCode::JETSTREAM_NOT_ENABLED => eprintln!("JetStream is not enabled"),
        ErrorCode::MAXIMUM_STREAMS_LIMIT => eprintln!("Stream limit reached"),
        _ => eprintln!("Unhandled JetStream error: {:?}", code),
    }
}
```
