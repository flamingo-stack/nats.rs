Wraps a `crate::Message` with JetStream-specific acknowledgment methods and provides types for messages received directly from NATS streams.

## Key Components

- **`Message`** — A JetStream message wrapping `crate::Message` with a `Context`. Implements `Deref` to the inner message.
- **`StreamMessage`** — A message received directly from a stream (without a consumer), containing subject, sequence number, headers, payload, and timestamp.
- **`Acker`** — Produced by `Message::split()`, holds the ack context separately from the message payload.
- **`AckKind`** — Enum of acknowledgment variants (`Ack`, `Nak`, etc.) used with `ack_with`.
- **`StreamMessageError` / `StreamMessageErrorKind`** — Error types for parsing stream messages, covering `MissingHeader` and `ParseError`.

## Key Methods on `Message`

| Method | Description |
|---|---|
| `ack()` | Sends `+ACK` to the server |
| `ack_with(kind)` | Sends a specific `AckKind` (e.g., Nak, Term) |
| `double_ack()` | Sends `+ACK` and awaits server confirmation for exactly-once semantics |
| `split()` | Separates the message from its `Acker` to reduce memory footprint |
| `info()` | Parses the `$JS.ACK.*` reply subject into a structured `Info` |

## Usage Example

```rust
use async_nats::jetstream::consumer::PullConsumer;
use async_nats::jetstream::AckKind;
use futures_util::StreamExt;

let client = async_nats::connect("localhost:4222").await?;
let jetstream = async_nats::jetstream::new(client);

let consumer: PullConsumer = jetstream
    .get_stream("events").await?
    .get_consumer("pull").await?;

let mut messages = consumer.fetch().max_messages(100).messages().await?;

while let Some(message) = messages.next().await {
    let msg = message?;
    // Standard ack
    msg.ack().await?;
    // Or ack with a specific kind
    msg.ack_with(AckKind::Nak(None)).await?;
    // Or split for deferred acking
    let (payload, acker) = msg.split();
}
```
