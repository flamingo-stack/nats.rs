Represents NATS JetStream account information and resource limits returned from the server. Used to inspect storage usage, stream/consumer counts, API request statistics, and account-level limits.

## Key Components

| Type | Description |
|---|---|
| `Account` | Top-level account statistics including storage, streams, consumers, domain, limits, and tier map |
| `Tier` | Per-tier resource usage and limits (mirrors `Account` fields for multi-tenant setups) |
| `Limits` | JetStream resource caps: max memory/storage, max streams/consumers, ACK pending, stream byte limits |
| `Requests` | API request counters (total, errors, and optionally inflight/level on server 2.11+) |

**Note:** Negative server values for `Limits` fields (indicating "unlimited") are deserialized as `None` via the internal `negative_as_none` helper.

## Usage Example

```rust
use async_nats::jetstream;

let client = async_nats::connect("nats://localhost:4222").await?;
let jetstream = jetstream::new(client);

let account: jetstream::account::Account = jetstream.get_account_info().await?;

println!("Memory used: {} bytes", account.memory);
println!("Storage used: {} bytes", account.storage);
println!("Active streams: {}", account.streams);
println!("Active consumers: {}", account.consumers);

if let Some(max_streams) = account.limits.max_streams {
    println!("Max streams allowed: {}", max_streams);
} else {
    println!("Max streams: unlimited");
}

println!("API requests total: {}", account.requests.total);
println!("API errors: {}", account.requests.errors);

for (tier_name, tier) in &account.tiers {
    println!("Tier '{}': {} streams, {} consumers", tier_name, tier.streams, tier.consumers);
}
```
