Defines the low-level `Response` enum for deserializing JetStream API responses, wrapping either a successful payload or a JetStream error.

## Key Components

- **`Response<T>`** — A generic, untagged enum that represents the two possible outcomes of a JetStream request:
  - `Ok(T)` — A successful response containing the deserialized payload of type `T`
  - `Err { error }` — A JetStream-level error (`super::errors::Error`)

## Usage Example

```rust
use serde::Deserialize;
use crate::jetstream::response::Response;

#[derive(Debug, Deserialize)]
struct StreamInfo {
    // ...stream fields
}

// Deserializing a raw JetStream API response
let raw = r#"{"error":{"code":404,"description":"stream not found"}}"#;
let resp: Response<StreamInfo> = serde_json::from_str(raw).unwrap();

match resp {
    Response::Ok(info) => println!("Stream info: {:?}", info),
    Response::Err { error } => eprintln!("JetStream error: {:?}", error),
}
```

> The `#[serde(untagged)]` attribute allows Serde to automatically select the correct variant based on the presence of an `error` field in the JSON payload, without requiring a discriminator key.
