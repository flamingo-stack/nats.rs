Defines the `Auth` struct used to hold NATS client authentication credentials and callback configuration.

## Key Components

- **`Auth`** — Public struct containing all supported authentication fields:
  - `jwt` — Optional JWT string for user authentication
  - `nkey` — Optional NKey seed or public key
  - `signature_callback` — Internal callback (`CallbackArg1`) invoked to sign a server nonce, returning a `Result<String, AuthError>`
  - `signature` — Optional raw signature bytes
  - `username` / `password` — Optional credentials for basic auth
  - `token` — Optional token-based authentication string

- **`Auth::new()`** — Convenience constructor delegating to `Auth::default()`

## Usage Example

```rust
use async_nats::Auth;

// Token-based auth
let auth = Auth {
    token: Some("my-secret-token".to_string()),
    ..Auth::default()
};

// Username/password auth
let auth = Auth {
    username: Some("user".to_string()),
    password: Some("pass".to_string()),
    ..Auth::default()
};

// JWT + NKey auth with signature callback
let auth = Auth {
    jwt: Some("eyJ...".to_string()),
    nkey: Some("SUANKEY...".to_string()),
    ..Auth::new()
};
```

## Notes

- Only one authentication method should be populated at a time; the NATS server will use whichever is present.
- `signature_callback` is `pub(crate)` and is typically set internally via connection options rather than directly.
