Async utility module for loading and parsing NATS credentials files, extracting JWTs and NKeys for client authentication.

## Key Components

| Item | Description |
|------|-------------|
| `load_creds(path)` | Async function that reads a credentials file from disk using Tokio non-blocking I/O |
| `parse_jwt_and_key_from_creds(contents)` | Parses raw credentials file content, returning a JWT string slice and a `KeyPair` |
| `USER_CONFIG_RE` | Lazy-initialized regex that matches PEM-style decorated blocks in credentials files |
| `parse_decorated_jwt(contents)` | Extracts the first decorated block (JWT) from credentials content |
| `parse_decorated_nkey(contents)` | Extracts the second decorated block (NKey seed) from credentials content |

## Usage Example

```rust
use std::path::Path;

// Load and parse a NATS credentials file
let path = Path::new("/home/user/.nkeys/creds/synadia/myaccount/myaccount.creds");

let contents = load_creds(&path).await?;
let (jwt, keypair) = parse_jwt_and_key_from_creds(&contents)?;

// jwt: &str  — the user JWT for CONNECT handshake
// keypair: nkeys::KeyPair — used to sign the server nonce
```

**Expected credentials file format:**

```text
-----BEGIN NATS USER JWT-----
eyJ0eXAiOiJqd3QiLCJhbGciOiJlZDI1NTE5...
------END NATS USER JWT------

-----BEGIN USER NKEY SEED-----
SUAIO3FHUX5PNV2LQIIP7TZ3N4L7TX3W53MQGEIVYFIGA635OZCKEYHFLM
------END USER NKEY SEED------
```

> All items are `pub(crate)` — this module is internal to the NATS client and not part of the public API.
