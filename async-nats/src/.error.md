Generic error type for the NATS client that wraps an error kind alongside an optional source error, enabling structured, domain-specific error handling across the library.

## Key Components

- **`Error<Kind>`** — Generic struct parameterized over a `Kind` type (must implement `Clone + Debug + Display + PartialEq`), carrying the error kind and an optional boxed source error.
- **`Error::new(kind)`** — Constructs an error with no source.
- **`Error::with_source(kind, source)`** — Constructs an error wrapping an upstream cause, accepting anything that converts into `crate::Error`.
- **`Error::kind()`** — Returns a clone of the error kind (avoids requiring `Copy`).
- **`Display`** — Formats as `"kind: source"` when a source is present, or just `"kind"` otherwise.
- **`From<Kind>`** — Allows converting a bare kind value directly into `Error<Kind>` via `into()`.

## Usage Example

```rust
use std::fmt::{Display, Formatter};

#[derive(Clone, Debug, PartialEq)]
enum ConnectErrorKind {
    Timeout,
    AuthFailure,
}

impl Display for ConnectErrorKind {
    fn fmt(&self, f: &mut Formatter<'_>) -> std::fmt::Result {
        match self {
            Self::Timeout => write!(f, "connection timed out"),
            Self::AuthFailure => write!(f, "authentication failed"),
        }
    }
}

type ConnectError = async_nats::error::Error<ConnectErrorKind>;

// Create a simple error
let err = ConnectError::new(ConnectErrorKind::Timeout);
assert_eq!(err.kind(), ConnectErrorKind::Timeout);

// Wrap a source error
let io_err = std::io::Error::other("network unreachable");
let err = ConnectError::with_source(ConnectErrorKind::Timeout, io_err);
println!("{err}"); // "connection timed out: network unreachable"

// Convert from kind directly
let err: ConnectError = ConnectErrorKind::AuthFailure.into();
```
