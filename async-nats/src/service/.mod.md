Implements the NATS micro-service framework for async_nats, providing service registration, discovery, and lifecycle management via the `$SRV` API prefix.

## Key Components

| Component | Description |
|---|---|
| `Service` | Core service instance managing endpoints, stats, and shutdown lifecycle |
| `ServiceBuilder` | Fluent builder for configuring and starting a `Service` |
| `ServiceExt` | Extension trait on `Client` exposing `add_service()` and `service_builder()` |
| `Config` | Service configuration including name, version, description, metadata, and queue group |
| `Info` | Service discovery response containing endpoint metadata |
| `Stats` | Runtime statistics response for all endpoints |
| `PingResponse` | Response payload for `$SRV.PING` requests |
| `Verb` | Enum of service discovery verbs: `Ping`, `Stats`, `Info`, `Schema` |
| `Endpoints` | Internal shared state tracking per-endpoint statistics |

**Constants:**
- `SERVICE_API_PREFIX` — `$SRV`
- `DEFAULT_QUEUE_GROUP` — `q`
- `NATS_SERVICE_ERROR` / `NATS_SERVICE_ERROR_CODE` — standard error header names

## Usage Example

```rust
use async_nats::service::ServiceExt;
use futures_util::StreamExt;

#[tokio::main]
async fn main() -> Result<(), async_nats::Error> {
    let client = async_nats::connect("demo.nats.io").await?;

    // Using the builder pattern
    let mut service = client
        .service_builder()
        .description("Product catalog service")
        .stats_handler(|name, stats| serde_json::json!({ "endpoint": name }))
        .queue_group("products")
        .start("products", "1.2.0")
        .await?;

    // Register an endpoint and handle requests
    let mut endpoint = service.endpoint("get").await?;
    while let Some(request) = endpoint.next().await {
        request.respond(Ok("hello".into())).await?;
    }

    Ok(())
}
```

Service names must match `[A-Za-z0-9\-_]+` and versions must be valid [SemVer](https://semver.org/) strings — both are validated at startup.
