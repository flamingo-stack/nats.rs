Defines a serializable error type for NATS service request failures, carrying an HTTP-style status message and numeric error code.

## Key Components

- **`Error`** — Public struct implementing `std::error::Error`, `Display`, `Serialize`, and `Deserialize`. Contains:
  - `status: String` — Human-readable error status message
  - `code: usize` — Numeric error code (analogous to an HTTP status code)

## Usage Example

```rust
use serde_json;

let err = Error {
    status: "Not Found".to_string(),
    code: 404,
};

// Display formatting
println!("{}", err); 
// → "service request error code: Not Found, status: 404"

// Serialize to JSON
let json = serde_json::to_string(&err).unwrap();
// → {"status":"Not Found","code":404}

// Use as a boxed error
let boxed: Box<dyn std::error::Error> = Box::new(err.clone());

// Deserialize from JSON
let decoded: Error = serde_json::from_str(&json).unwrap();
assert_eq!(decoded, err);
```

## Notes

- Derives `Clone`, `PartialEq`, and `Eq`, making it safe to compare and copy across service boundaries.
- Intended for use with NATS service API responses where the server returns structured error payloads.
