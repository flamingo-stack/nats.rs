Defines the `Endpoint` stream and associated statistics types for NATS service endpoints, handling request routing, graceful shutdown, and metrics tracking.

## Key Components

- **`Endpoint`** — Implements `Stream<Item = Request>`, wrapping a `Subscriber` to yield incoming service requests. Handles cooperative shutdown via a broadcast channel, unsubscribing cleanly when a stop signal is received.
- **`Endpoint::stop()`** — Async method to explicitly unsubscribe the endpoint from its subject.
- **`Stats`** — Public struct exposing per-endpoint metrics: request count, error count, processing time, average processing time, last error, and queue group.
- **`Inner`** — Internal counterpart to `Stats`, including additional fields (`kind`, `metadata`) used for wire serialization before conversion via `From<Inner> for Stats`.
- **`Info`** — Describes endpoint configuration (name, subject, queue group, metadata); used in service info responses.
- **`serde_error_string`** — Private serde module serializing `Option<error::Error>` as `"code:status"` strings (or `""` for `None`), with tolerant deserialization for missing or invalid codes.
- **`null_meta_as_default`** — Deserializer helper that coerces a JSON `null` metadata field into an empty `HashMap`.

## Usage Example

```rust
use futures_util::StreamExt;

// Endpoint is typically obtained from a Service, not constructed directly.
// Once you have one, consume it as an async stream:
while let Some(request) = endpoint.next().await {
    request.respond(Ok("pong".into())).await?;
}

// Gracefully stop the endpoint and unsubscribe:
endpoint.stop().await?;
```
