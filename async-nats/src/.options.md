Configures and establishes connections to a NATS server with customizable authentication, TLS, and connection behavior options.

## Key Components

- **`ConnectOptions`** — Builder struct for NATS connection configuration. Implements `Default`, `Debug`, and a fluent builder API.
- **`ConnectOptions::new()`** — Creates a default `ConnectOptions` instance.
- **`ConnectOptions::connect()`** — Consumes options and establishes a connection, returning a `Client`.
- **Authentication builders:**
  - `with_token` / `token` — Token-based auth
  - `with_user_and_password` / `user_and_password` — Username/password auth
  - `with_nkey` / `nkey` — NKey seed auth
  - `with_auth_callback` — Async callback receiving the server nonce, returning `Auth`
- **TLS fields** — `tls_required`, `tls_first`, `certificates`, `client_cert`, `client_key`, `tls_client_config`
- **Tuning fields** — `ping_interval`, `subscription_capacity`, `sender_capacity`, `read_buffer_capacity`, `reconnect_delay_callback`

## Usage Example

```rust
use std::time::Duration;

#[tokio::main]
async fn main() -> Result<(), async_nats::ConnectError> {
    // Basic TLS connection
    let client = async_nats::ConnectOptions::new()
        .require_tls(true)
        .ping_interval(Duration::from_secs(30))
        .connect("demo.nats.io")
        .await?;

    // Token auth
    let client = async_nats::ConnectOptions::with_token("t0k3n!".into())
        .connect("demo.nats.io")
        .await?;

    // Async auth callback with nonce signing
    let client = async_nats::ConnectOptions::with_auth_callback(move |_nonce| async move {
        let mut auth = async_nats::Auth::new();
        auth.username = Some("derek".to_string());
        auth.password = Some("s3cr3t".to_string());
        Ok(auth)
    })
    .connect("demo.nats.io")
    .await?;

    Ok(())
}
```
