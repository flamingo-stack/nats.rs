Provides NATS message header types and utilities for constructing, manipulating, and serializing HTTP-like headers for use with the `async_nats` client.

## Key Components

- **`HeaderMap`** – The primary struct for managing NATS headers; backed by a `HashMap<HeaderName, Vec<HeaderValue>>`. Supports insert, append, get, get\_last, get\_all, and iteration. Serializes to the `NATS/1.0\r\n` wire format via `to_bytes()`.
- **`HeaderValue`** – A newtype wrapper around `String` representing a single header value. Implements `From` for common numeric and string types; rejects values containing `\r` or `\n` via `FromStr`.
- **`HeaderName`** – Represents a header name using either a standard predefined variant (`StandardHeader` enum) or a custom string (`HeaderRepr::Custom`).
- **`GetAll<'a, T>`** – An iterator returned by `HeaderMap::get_all`, yielding all values for a given key.
- **`IntoHeaderName` / `IntoHeaderValue`** – Conversion traits allowing `&str`, `String`, and the typed structs to be used interchangeably in header operations.
- **`ParseHeaderValueError`** – Error type returned when a header value contains invalid characters (`\r` or `\n`).
- **`standard_headers!` macro** – Generates `StandardHeader` enum variants and associated `pub const` `HeaderName` values (e.g., `NATS_SUBJECT`) with zero-copy `&'static str` lookups.

## Usage Example

```rust
use async_nats::HeaderMap;

// Build a header map
let mut headers = HeaderMap::new();
headers.insert("Trace-Id", "abc-123");
headers.append("X-Tag", "first");
headers.append("X-Tag", "second");

// Retrieve values
let trace = headers.get("Trace-Id").unwrap();
println!("{}", trace); // "abc-123"

// Iterate all values for a key
for val in headers.get_all("X-Tag") {
    println!("{}", val);
}

// Use a predefined constant header name
use async_nats::header::NATS_SUBJECT;
headers.insert(NATS_SUBJECT, "events.user.created");
```
