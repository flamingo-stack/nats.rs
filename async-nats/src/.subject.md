An immutable, UTF-8 validated string type for NATS subject names, backed by `bytes::Bytes` for efficient zero-copy operations.

## Key Components

### `Subject`
The core struct wrapping `bytes::Bytes` with UTF-8 validity guarantees. Implements `Deref<Target = str>`, `AsRef<str>`, `Display`, `Serialize`/`Deserialize`, and standard ordering/equality traits.

**Constructors:**
- `from_static(s: &'static str)` — zero-allocation construction from static strings
- `from_utf8<T: Into<Bytes>>(input: T)` — validated construction from byte vectors, returns `Utf8Error` on failure
- `unsafe from_bytes_unchecked(bytes: Bytes)` — unchecked construction, caller must guarantee UTF-8

**Methods:**
- `as_str() -> &str` — extracts a string slice
- `into_string() -> String` — consumes the `Subject`, converting to owned `String`

### `ToSubject` Trait
Conversion trait implemented for `Subject`, `&'static str`, and `String`, enabling ergonomic subject creation across common string types.

## Usage Example

```rust
use async_nats::Subject;
use bytes::Bytes;

// From a static string (zero-copy)
let subject = Subject::from_static("events.user.created");

// From an owned String
let subject = Subject::from("events.user.updated".to_string());

// From raw bytes with UTF-8 validation
let subject = Subject::from_utf8(b"events.user.deleted".to_vec()).unwrap();

// Unsafe construction from Bytes (caller guarantees UTF-8)
let bytes = Bytes::from_static(b"events.system.boot");
let subject = unsafe { Subject::from_bytes_unchecked(bytes) };

// Use as a string slice via Deref
println!("Subject: {}", subject.as_str());

// Convert to owned String
let s: String = subject.into_string();
```

## Notes

- All constructors enforce UTF-8 validity at construction time, making `Deref` to `str` always safe without runtime checks.
