## About

`nats.rs` is the Flamingo-maintained fork of the official NATS Rust async client. It provides the `async-nats` crate — a Tokio-based library for building services that communicate over NATS — extended with OpenFrame-specific JWT token refresh support.

- **Upstream:** [nats-io/nats.rs](https://github.com/nats-io/nats.rs)
- **Fork maintained by:** [Flamingo](https://flamingo.run) / [OpenFrame](https://openframe.ai)
- **Community:** [OpenMSP Slack](https://www.openmsp.ai/)
