A test utility library for spawning, managing, and cleaning up local NATS server processes during integration tests. Supports single-server and 3-node cluster configurations with automatic port allocation, log management, and graceful shutdown.

## Key Components

- **`Server`** — Wraps a running `nats-server` child process; implements `Drop` to kill the process and clean up JetStream storage and log files automatically.
- **`Cluster`** — Holds a 3-node `Server` array for cluster testing, exposing `client_url()` from the first node.
- **`run_server(cfg)`** — Spawns a single NATS server with a given config file path.
- **`run_basic_server()`** — Spawns a minimal NATS server with no config.
- **`run_server_with_port(cfg, port)`** — Spawns a server on a specific port (or dynamic with `None`).
- **`run_cluster(cfg)`** — Starts a 3-node cluster with automatically allocated, non-conflicting ports; accepts a single config string or `[&str; 3]` per node via `IntoConfig`.
- **`set_lame_duck_mode(s)`** — Sends the `ldm` signal to a running server via `nats-server --signal`.
- **`is_port_available(port)`** — Checks if a TCP port is free by attempting to bind it.
- **`Server::client_url()`** — Reads the server INFO handshake to return the actual `nats://` or `tls://` URL, useful when dynamic ports are used.
- **`Server::restart()`** — Kills and re-spawns the server process with the same config and port.

## Usage Example

```rust
use nats_server_util::{run_basic_server, run_server, run_cluster};

// Single server — cleans up on drop
let server = run_basic_server();
let client = async_nats::connect(server.client_url()).await.unwrap();

// Server with a config file
let server = run_server("configs/jetstream.conf");

// 3-node cluster with shared config
let cluster = run_cluster("configs/jetstream.conf");
let client = async_nats::connect(cluster.client_url()).await.unwrap();

// 3-node cluster with per-node configs
let cluster = run_cluster(["configs/n1.conf", "configs/n2.conf", "configs/n3.conf"]);
```
