A CLI entry point for launching a configurable NATS test server, primarily used for testing client reconnection logic and fault tolerance behaviors.

## Key Components

- **`Args` struct** — Holds parsed CLI configuration including `host`, `port`, `bugginess`, and `hop_ports`
- **`Args::default()`** — Defaults: host `0.0.0.0`, port `4222`, bugginess `200`, hop_ports `false`
- **`Args::parse()`** — Parses `--key=value` style CLI arguments from `std::env::args()`
- **`parse<I, T>()` helper** — Generic iterator-based value parser with usage-string error messages
- **`main()`** — Initializes `env_logger`, parses args, and spawns the `NatsTestServer`

## CLI Options

| Flag | Default | Description |
|---|---|---|
| `--host=<s>` | `0.0.0.0` | Host address to bind |
| `--port=<n>` | `4222` | Port to listen on |
| `--bugginess=<n>` | `200` | 1-in-N chance of operation failure |
| `--hop-ports` | `false` | Enable port-hopping for reconnect testing |

## Usage Example

```bash
# Run with defaults
cargo run --bin nats_test_server

# Run with custom port and high fault injection rate
cargo run --bin nats_test_server -- --port=4333 --bugginess=10

# Enable port-hopping for reconnection testing
cargo run --bin nats_test_server -- --hop-ports --port=4222
```

```rust
// Equivalent programmatic usage via the underlying library
nats_test_server::NatsTestServer::build()
    .address("0.0.0.0:4222".parse().unwrap())
    .bugginess(200)
    .hop_ports(false)
    .spawn()
    .join()
    .unwrap();
```
