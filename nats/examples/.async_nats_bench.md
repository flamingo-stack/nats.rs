A benchmarking tool for measuring async NATS publish/subscribe throughput, reporting message frequency and throughput in MB/s.

## Key Components

- **`Args`** — CLI argument struct (via `structopt`) configuring server URL, credentials, message size, message count, publisher/subscriber concurrency, TLS, and subject
- **`main`** — Orchestrates concurrent publisher and subscriber threads synchronized via a `Barrier`, times total execution, and prints throughput metrics

## Usage Example

```bash
# Basic publish benchmark: 100k messages, 128 bytes, 4 publishers
async_nats_bench --url nats://127.0.0.1:4222 \
  -n 100000 \
  --message-size 128 \
  -p 4 \
  bench.subject

# With subscribers and TLS credentials
async_nats_bench --url nats://myserver:4222 \
  --creds /path/to/user.creds \
  -tls \
  -p 2 -s 2 \
  -n 50000 \
  bench.subject
```

```text
Starting benchmark [msgs=100000, msgsize=128, pubs=4, subs=0]
duration: 1.234s frequency: 81037 mbps: 9
```

## Notes

- Message count is automatically rounded up to the nearest multiple of the publisher count to ensure even distribution
- All publisher and subscriber threads are started simultaneously using a shared `Arc<Barrier>`, ensuring a clean measurement window
- Uses `smol` as the async executor — each OS thread runs its own `smol::block_on` loop
- Minimum elapsed time is clamped to 1 ms to avoid division by zero
