A CLI utility for interacting with a NATS messaging server, supporting publish, subscribe, request, and reply operations with optional credential-based or token-based authentication.

## Key Components

### `Cli` (struct)
Top-level argument parser built with `StructOpt`. Accepts:
- `--server` / `-s` — NATS server address (defaults to `demo.nats.io`)
- `--creds` — Path to a user credentials file (mutually exclusive with `--auth-token`)
- `--auth-token` — Server authorization token (mutually exclusive with `--creds`)

### `Command` (enum)
Subcommands dispatched from the CLI:

| Variant | Description |
|---|---|
| `pub` | Publishes a message to a subject |
| `sub` | Subscribes and prints incoming messages; optionally parses as JSON |
| `request` | Sends a request and waits for a single reply |
| `reply` | Queue-subscribes to a subject and responds to every request |

### `main()`
Parses CLI args, builds a `nats::Options` connection (with disconnect/reconnect callbacks), then pattern-matches on the subcommand to invoke the appropriate NATS operation.

## Usage Example

```bash
# Publish a message
nats-box pub my.subject "hello world"

# Subscribe and pretty-print JSON payloads
nats-box sub my.subject --json

# Send a request and wait for a reply
nats-box request my.service "ping"

# Listen for requests and auto-reply
nats-box reply my.service "pong"

# Connect with a credentials file
nats-box --creds /path/to/user.creds sub my.subject

# Connect to a custom server with a token
nats-box --server nats://localhost:4222 --auth-token mytoken pub test "hi"
```
