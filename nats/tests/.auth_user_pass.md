Demonstrates integration tests for username/password authentication against a NATS server, verifying connection behavior with valid credentials, invalid credentials, and credential override scenarios.

## Key Components

- **`basic_user_pass_auth`** — Test function covering three authentication scenarios:
  - Unauthenticated connection (expects failure)
  - `Options::with_user_pass` credential injection (expects success)
  - URL-embedded credentials via `client_url_with` (expects success)
  - URL credentials overriding `Options` credentials (expects URL credentials win)

## Usage Example

```rust
// Connect using Options::with_user_pass
let nc = nats::Options::with_user_pass("derek", "s3cr3t")
    .connect("nats://localhost:4222")?;

// Alternatively, embed credentials directly in the URL
let nc = nats::connect("nats://derek:s3cr3t@localhost:4222")?;
```

## Notes

- Requires a running NATS server configured with `tests/configs/user_pass.conf`
- URL-embedded credentials take precedence over those supplied via `Options::with_user_pass`
- Source: [`tests/auth_user_pass.rs`](https://github.com/flamingo-stack/nats.rs/blob/main/tests/auth_user_pass.rs)
