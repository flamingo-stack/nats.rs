Comprehensive integration test suite for NATS JetStream functionality, validating publish/subscribe operations, consumer management, durable subscriptions, and error handling against a live NATS server.

## Key Components

| Test Function | Purpose |
|---|---|
| `jetstream_not_enabled` | Verifies correct error (`NotEnabled`) when JetStream is unavailable on the server |
| `jetstream_account_not_enabled` | Confirms `NotEnabledForAccount` error for accounts without JetStream access |
| `jetstream_publish` | Tests basic publish, publish with options (stream expectations, sequence expectations, message IDs, deduplication) |
| `jetstream_subscribe` | Validates ephemeral push subscriptions, message acknowledgment, drain, and unsubscribe behavior |
| `jetstream_subscribe_durable` | Tests durable consumer creation, re-subscription, delivery subject rotation, and consumer cleanup |
| `jetstream_queue_subscribe` | Exercises queue group subscriptions with durable names, cross-subject/group conflict detection |

## Usage Example

```rust
use nats::jetstream::{self, StreamConfig, PublishOptions, SubscribeOptions};

// Connect and create a JetStream context
let nc = nats::connect("nats://localhost:4222").unwrap();
let js = nats::jetstream::new(nc);

// Create a stream
js.add_stream(StreamConfig {
    name: "ORDERS".to_string(),
    subjects: vec!["orders.*".to_string()],
    ..Default::default()
}).unwrap();

// Publish with deduplication ID
let ack = js.publish_with_options("orders.new", b"payload", &PublishOptions {
    id: Some("msg-001".to_string()),
    ..Default::default()
}).unwrap();

// Durable push subscription
let sub = js.subscribe_with_options(
    "orders.new",
    &SubscribeOptions::new().durable_name("my-consumer".to_string()),
).unwrap();

let msg = sub.next().unwrap();
msg.ack().unwrap();
```

## Notes

- Tests require a running NATS server with JetStream enabled; config fixtures are loaded from `tests/configs/`
- The `jetstream_not_enabled` test is marked `#[ignore]` as it requires a basic server without JetStream
- Source: [`tests/jetstream.rs`](https://github.com/flamingo-stack/nats.rs/blob/main/tests/jetstream.rs)
