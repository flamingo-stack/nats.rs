Integration tests for the NATS JetStream Object Store feature, verifying storage, retrieval, deletion, watching, and digest validation of binary objects backed by JetStream streams.

## Key Components

| Test | Description |
|---|---|
| `object_random` | Stores and retrieves a 1MB+ random byte payload using multiple read buffer sizes (1, 2, 128 bytes) |
| `object_sealed` | Verifies that sealing a bucket marks the underlying `OBJ_*` stream as sealed |
| `object_delete` | Confirms deletion leaves a tombstone/delete marker message in the stream |
| `object_multiple_delete` | Validates that deleting one object does not affect message counts for other objects |
| `object_names` | Tests valid and invalid object key names (empty strings must fail; wildcards are accepted) |
| `object_info_modified` | Asserts that the `modified` timestamp on object info is populated after a `put` |
| `object_watch` | Verifies the watch iterator yields `ObjectInfo` entries as objects are added |
| `object_digest` | Cross-validates SHA-256 digests against known reference files |

## Usage Example

```rust
// Requires the "unstable" feature flag
let server = nats_server::run_server("tests/configs/jetstream.conf");
let client = nats::connect(server.client_url()).unwrap();
let context = nats::jetstream::new(client);

let bucket = context
    .create_object_store(&nats::object_store::Config {
        bucket: "MY_BUCKET".to_string(),
        ..Default::default()
    })
    .unwrap();

// Store an object
let data = b"hello world".to_vec();
bucket.put("greeting", &mut data.as_slice()).unwrap();

// Retrieve an object
let mut result = Vec::new();
bucket.get("greeting").unwrap().read_to_end(&mut result).unwrap();
```
