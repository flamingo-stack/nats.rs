Integration test verifying that a JetStream pull consumer's `fetch` operation correctly returns `None` when no messages are available, rather than blocking indefinitely.

## Key Components

- **`no_messages()`** — Test function that:
  - Spins up a local NATS server with JetStream enabled via `jetstream.conf`
  - Creates a stream `TEST` subscribed to subject `"foo"`
  - Adds a durable pull consumer `CONSUMER`
  - Issues a `fetch` with `no_wait: true` and a batch size of `10`
  - Asserts that the iterator immediately returns `None` on an empty stream

## Usage Example

```rust
// Demonstrates the no_wait fetch pattern for empty streams
let consumer = js
    .pull_subscribe_with_options(
        "foo",
        &PullSubscribeOptions::new().durable_name("CONSUMER".to_string()),
    )
    .unwrap();

let mut batch = consumer
    .fetch(BatchOptions {
        batch: 10,
        expires: None,
        no_wait: true, // returns immediately if no messages exist
    })
    .unwrap();

// Returns None rather than blocking when the stream is empty
assert!(batch.next().is_none());
```

## Notes

- The `no_wait: true` flag triggers a NATS `404` status response when the stream has no pending messages; the client library intercepts this and converts the blocking iterator to an immediate `None` rather than hanging.
