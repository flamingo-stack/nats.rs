Verifies slow consumer detection behavior in the NATS client, ensuring that excess messages are dropped and the error callback is triggered correctly when a subscription's message buffer is exceeded.

## Key Components

- **`slow_consumers` test** — Integration test that validates the full slow consumer lifecycle: server setup, subscription limits, message overflow, and drop accounting.
- **`AtomicUsize` drop counter** — Thread-safe counter incremented by the error callback each time a slow consumer drop event is detected.
- **`set_message_limits(100)`** — Caps the subscription's internal buffer at 100 messages, causing overflow when more are published.
- **`sub.dropped_messages()`** — Returns the number of messages dropped by the subscription due to buffer overflow.

## Usage Example

```rust
use std::sync::{atomic::AtomicUsize, Arc};

let dropped = Arc::new(AtomicUsize::new(0));

let nc = nats::Options::with_user_pass("user", "pass")
    .error_callback({
        let dropped = dropped.clone();
        move |err| {
            if err.to_string().contains("slow consumer") {
                dropped.fetch_add(1, std::sync::atomic::Ordering::SeqCst);
            }
        }
    })
    .connect("nats://localhost:4222")?;

let sub = nc.subscribe("data")?;
sub.set_message_limits(100); // drop messages beyond 100 queued

// After publishing 140 messages, 40 will be dropped
assert_eq!(sub.dropped_messages()?, 40);
```

## Notes

- The error callback string match is exact — slow consumer errors emit a fixed message referencing the subject name.
- The `thread::sleep` after publishing is required to allow the server to flush messages before the consumer drains the buffer.
