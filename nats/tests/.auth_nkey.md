NKey authentication integration test for NATS server connections using cryptographic key pairs.

## Key Components

- **`basic_nkey_auth`** — Integration test that verifies NKey-based authentication by connecting to a NATS server configured with NKey auth (`tests/configs/nkey.conf`), signing a server nonce with an NKey `KeyPair`, and confirming a successful connection.

## Usage Example

```rust
// Connect to a NATS server using NKey authentication
let nkey = "UAMMBNV2EYR65NYZZ7IAK5SIR5ODNTTERJOBOF4KJLMWI45YOXOSWULM";
let seed = "SUANQDPB2RUOE4ETUA26CNX7FUKE5ZZKFCQIIW63OX225F2CO7UEXTM7ZY";
let kp = nkeys::KeyPair::from_seed(seed).unwrap();

nats::Options::with_nkey(nkey, move |nonce| kp.sign(nonce).unwrap())
    .connect("nats://localhost:4222")?;
```

## Notes

- Requires a NATS server running with NKey authentication enabled (see [`tests/configs/nkey.conf`](https://github.com/flamingo-stack/nats.rs/blob/main/tests/configs/nkey.conf))
- The `nkey` string is the public key (user identity); the `seed` is the private key used to sign nonces
- Uses the [`nkeys`](https://crates.io/crates/nkeys) crate for `KeyPair` creation and nonce signing
- The signing closure is passed to `Options::with_nkey`, which handles the challenge-response authentication flow automatically
