Demonstrates integration testing for NATS lame duck mode, verifying that a client connection receives a callback notification when the server transitions into lame duck mode (graceful shutdown).

## Key Components

- **`lame_duck_mode` test** — Integration test that connects a NATS client with a registered lame duck callback, triggers server lame duck mode, and asserts the callback fires within 500ms.

## Usage Example

```rust
use crossbeam_channel::bounded;
use std::time::Duration;

let (ltx, lrx) = bounded(1);

let nc = nats::Options::new()
    .lame_duck_callback(move || ltx.send(true).unwrap())
    .connect("nats://127.0.0.1:4222")
    .expect("could not connect");

// When the server enters lame duck mode, the callback fires
let received = lrx.recv_timeout(Duration::from_millis(500));
assert!(received.is_ok());
```

## Notes

- Skipped on Windows (`#[cfg_attr(target_os = "windows", ignore)]`) due to platform-level signal handling differences.
- Uses `crossbeam_channel::bounded` to safely communicate callback invocation across threads.
- The lame duck callback is registered via `nats::Options::lame_duck_callback` before establishing the connection.
