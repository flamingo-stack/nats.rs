Integration test suite for the NATS Key-Value store, validating CRUD operations, history tracking, watch subscriptions, bucket management, and domain-based leaf node connectivity using the `nats::kv` API.

## Key Components

| Test | Description |
|---|---|
| `key_value_entry` | Validates full entry lifecycle: `put`, `get`, `entry`, `delete`, `create`, `update`, and `status` |
| `key_value_short_history` | Confirms history truncation when entries exceed the configured limit (history=5, 10 puts) |
| `key_value_long_history` | Same as above at larger scale (history=25, 50 puts) |
| `key_value_watch` | Verifies wildcard-filtered watches (`foo.>`) receive only matching key events |
| `key_value_watch_all` | Validates `watch_all()` isolation — separate buckets do not bleed events across watchers |
| `key_value_bind` | Ensures `key_value()` binds to valid KV streams and rejects non-KV-prefixed streams |
| `key_value_delete` | Tests bucket deletion via `delete_key_value` and confirms re-binding fails |
| `key_value_purge` | Verifies `purge()` collapses key history to a single tombstone entry |
| `key_value_keys` | Validates `keys()` iterator respects deletions, purges, and TTL expiry |
| `key_value_domain` | *(ignored)* Happy-path check for KV operations across JetStream leaf node domains |

## Usage Example

```rust
use nats::kv::*;

let client = nats::connect("nats://localhost:4222").unwrap();
let context = nats::jetstream::new(client);

let kv = context
    .create_key_value(&Config {
        bucket: "MY_BUCKET".to_string(),
        history: 5,
        max_age: std::time::Duration::from_secs(3600),
        ..Default::default()
    })
    .unwrap();

// Put and retrieve
let revision = kv.put("key", b"value").unwrap();
let entry = kv.entry("key").unwrap().unwrap();
assert_eq!(entry.value, b"value");

// Conditional update
kv.update("key", b"new_value", revision).unwrap();

// Watch for changes
let mut watcher = kv.watch("key").unwrap();
let event = watcher.next().unwrap();
```

> **Note:** Requires the `unstable` feature flag (`--features unstable`) and a running NATS server with JetStream enabled. See [`tests/configs/jetstream.conf`](https://github.com/flamingo-stack/nats.rs/blob/main/tests/configs/jetstream.conf) for the test server configuration.
