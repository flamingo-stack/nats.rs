Manages NATS server connections, including TLS configuration, server discovery, reconnection logic with exponential backoff, and authentication handling.

## Key Components

- **`Connector`** — Core struct maintaining a map of server addresses with reconnect attempt counts, connection options, and TLS configuration.
- **`configure_tls()`** — Builds a `rustls::ClientConfig` by loading native system certs, user-provided CA certificates, and optional mTLS client cert/key pairs.
- **`Connector::new()`** — Initializes the connector with a list of server addresses and computes the TLS config.
- **`Connector::connect()`** — Attempts connection to a randomly shuffled server list, with optional exponential backoff. Discovers new servers from `INFO` messages and resets attempt counters on success.
- **`Connector::connect_addr()`** — Handles low-level connection to a single `SocketAddr`: TCP handshake, INFO parsing, TLS upgrade, and CONNECT message construction with full auth negotiation (`UserPass`, `Token`, `Credentials`/NKey).
- **`Connector::add_server()`** — Registers a newly discovered server address.
- **`Connector::get_servers()`** — Filters the server list by `max_reconnects` limit.

## Usage Example

```rust
use std::sync::Arc;
use nats::Options;
use nats::connector::{Connector, ServerAddress};

let options = Arc::new(Options::default());
let servers = vec!["nats://localhost:4222".parse::<ServerAddress>()?];

let mut connector = Connector::new(servers, options)?;

// Connect with exponential backoff enabled
let (server_info, stream) = connector.connect(true)?;

println!("Connected to NATS server version {}", server_info.version);
```
