A legacy synchronous Rust client library for the [NATS.io](https://nats.io/) messaging system. Provides publish/subscribe, request/response, JetStream, and key-value store functionality over a synchronous API.

> **Note:** This is the legacy client and will not receive new features. Use [`async-nats`](https://crates.io/crates/async-nats) for new projects.

## Key Components

| Export | Description |
|---|---|
| `Connection` | Primary NATS connection handle (cloneable via `Arc`) |
| `Options` | Builder for configuring connections (auth, TLS, etc.) |
| `Message` | Represents a received NATS message |
| `Subscription` / `Handler` | Synchronous message subscriber types |
| `ServerInfo` | Server metadata received during handshake |
| `HeaderMap` | HTTP-style headers for messages |
| `asynk` | Async API module |
| `jetstream` | JetStream stream/consumer management |
| `kv` | Key-value store (unstable feature) |
| `object_store` | Object store (unstable feature) |
| `IntoServerList` / `ServerAddress` | Server URL parsing utilities |

## Usage Example

```rust
use std::time::Duration;

fn main() -> std::io::Result<()> {
    // Basic connection
    let nc = nats::connect("demo.nats.io")?;

    // Connection with options (credentials, TLS, name)
    let nc = nats::Options::with_user_pass("user", "s3cr3t!")
        .with_name("My App")
        .connect("127.0.0.1")?;

    // Publish
    nc.publish("my.subject", "Hello World!")?;

    // Subscribe and iterate
    let sub = nc.subscribe("foo")?;
    for msg in sub.timeout_iter(Duration::from_secs(5)) {
        println!("Received: {}", msg);
    }

    // Request/response
    let resp = nc.request_timeout("foo", "Help?", Duration::from_secs(2))?;

    // Queue subscription
    let qsub = nc.queue_subscribe("foo", "my_group")?;

    Ok(())
}
```
