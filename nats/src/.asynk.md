Async NATS client wrapper that bridges the synchronous `nats::Connection` API to an async interface using `blocking::unblock` to offload blocking operations onto a thread pool.

## Key Components

- **`connect()`** — Async function to establish a NATS connection using a URL or server list
- **`Connection`** — Async wrapper around `crate::Connection`; all blocking I/O is dispatched via `unblock()`
- **`Subscription`** — Async wrapper around `crate::Subscription` with cooperative cancellation via a `crossbeam_channel` closer signal

### `Connection` Methods

| Method | Description |
|---|---|
| `publish` | Send a message to a subject |
| `publish_request` | Publish with a reply subject |
| `request` / `request_timeout` | Publish and await a single response |
| `request_multi` | Publish and return a subscription for multiple responses |
| `subscribe` / `queue_subscribe` | Create a subject or queue subscription |
| `flush` / `flush_timeout` | Round-trip flush to the server |
| `drain` / `close` | Graceful or immediate connection teardown |
| `new_inbox` | Generate a unique reply-inbox subject |

### `Subscription` Methods

| Method | Description |
|---|---|
| `next()` | Async receive; returns `None` when closed |
| `try_next()` | Non-blocking peek; returns `None` immediately if no message |
| `drain()` | Stop accepting new messages, drain remaining |
| `unsubscribe()` | Stop and discard remaining messages |

## Usage Example

```rust
smol::block_on(async {
    // Simple connection
    let nc = nats::asynk::connect("demo.nats.io").await?;

    // Publish a message
    nc.publish("greetings", "Hello, NATS!").await?;

    // Subscribe and receive
    let sub = nc.subscribe("greetings").await?;
    if let Some(msg) = sub.next().await {
        println!("Received: {:?}", msg);
    }

    // Request/response
    let reply = nc.request("service.ping", "ping").await?;

    // Authenticated connection with TLS
    let nc2 = nats::asynk::Options::with_credentials("my.creds")
        .connect("tls://connect.ngs.global")
        .await?;

    std::io::Result::Ok(())
});
```
