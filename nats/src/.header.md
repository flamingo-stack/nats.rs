Provides NATS message header parsing and manipulation for the NATS messaging protocol, implementing a multi-map structure that maps header names to sets of values with support for serialization/deserialization of the `NATS/1.0` wire format.

## Key Components

- **`HeaderMap`** — Core struct; a `HashMap<String, HashSet<String>>` multi-map for NATS message headers. Implements `Deref`, `FromIterator`, and `TryFrom<&[u8]>` for wire-format parsing.
- **`GetAll`** — View type for iterating all values associated with a single header key.
- **Well-known header constants** — `STATUS`, `DESCRIPTION`, `NATS_MSG_ID`, `NATS_EXPECTED_STREAM`, `NATS_EXPECTED_LAST_MSG_ID`, `NATS_EXPECTED_LAST_SEQUENCE`, `NATS_EXPECTED_LAST_SUBJECT_SEQUENCE`, `NATS_LAST_CONSUMER`, `NATS_CONSUMER_STALLED`.

### `HeaderMap` Methods

| Method | Description |
|--------|-------------|
| `new()` | Creates an empty `HeaderMap` |
| `insert(key, value)` | Sets a key to a single value, replacing any prior values |
| `append(key, value)` | Adds a value to the set for a key |
| `get(key)` | Returns one value for a key |
| `get_all(key)` | Returns all values for a key as a `GetAll` iterator view |
| `contains_key(key)` | Checks key existence |
| `clear()` / `is_empty()` | Map management |

## Usage Example

```rust
use nats::HeaderMap;
use nats::header::{STATUS, NATS_MSG_ID};

// Build headers
let mut headers = HeaderMap::new();
headers.insert(STATUS, "200");
headers.insert(NATS_MSG_ID, "msg-abc-123");
headers.append(STATUS, "OK"); // multiple values per key

// Read headers
if let Some(status) = headers.get(STATUS) {
    println!("Status: {}", status);
}

// Iterate all values for a key
for val in headers.get_all(STATUS) {
    println!("Status value: {}", val);
}

// Parse from wire format
use std::convert::TryFrom;
let raw = b"NATS/1.0 200 OK\r\nNats-Msg-Id: abc\r\n\r\n";
let parsed = HeaderMap::try_from(raw.as_ref()).unwrap();
```
