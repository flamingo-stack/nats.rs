Provides the JetStream at-least-once messaging module for NATS, exposing stream management, consumer configuration, subscriptions, and the core `JetStream` client context.

## Key Components

- **`JetStreamOptions`** — Configuration for the JetStream API connection, including custom API prefixes and domain-based routing.
- **`JetStream`** (via `jetstream::new`) — The primary client handle for all JetStream operations (streams, consumers, publish, subscribe).
- **`PullSubscription` / `PushSubscription`** — Re-exported subscription types for pull and push consumer models.
- **`ErrorCode`** — Exhaustive enum of server-returned JetStream API error codes (e.g., `StreamNotFound`, `ConsumerNotFound`, `NotEnabled`).
- **`ApiResponse<T>`** — Internal serde-tagged enum handling both success and error deserialization from the JetStream JSON API.
- **`types`** — Re-exported types including `StreamConfig`, `ConsumerConfig`, `StorageType`, `PullSubscribeOptions`, and related structs.

## Usage Example

```rust
use nats::jetstream::{StorageType, StreamConfig, ConsumerConfig};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let nc = nats::connect("nats://localhost:4222")?;
    let js = nats::jetstream::new(nc);

    // Create a memory-backed stream
    js.add_stream(StreamConfig {
        name: "events".to_string(),
        storage: StorageType::Memory,
        max_bytes: 5 * 1024 * 1024 * 1024,
        ..Default::default()
    })?;

    // Create a durable push consumer
    js.add_consumer("events", ConsumerConfig {
        durable_name: Some("processor".to_string()),
        deliver_subject: Some("events.deliver".to_string()),
        ..Default::default()
    })?;

    // Subscribe (binds to existing consumer or creates ephemeral)
    let sub = js.subscribe("events")?;

    Ok(())
}
```
