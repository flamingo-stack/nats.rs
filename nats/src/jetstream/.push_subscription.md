Implements JetStream push-based subscriptions for NATS, providing both blocking and non-blocking message consumption patterns with automatic flow control, idle heartbeat filtering, and consumer lifecycle management.

## Key Components

### `PushSubscription`
The primary public type — a cloneable, reference-counted handle to an active JetStream push consumer. Wraps `Arc<Inner>` for cheap cloning.

### `Inner`
Internal subscription state holding the channel receiver, stream/consumer names, ack policy, pending message count, consumer ownership flag, and the JetStream context. Implements `Drop` to automatically unsubscribe and optionally delete the consumer on cleanup.

### Message Retrieval Methods

| Method | Behavior |
|---|---|
| `next()` | Blocking — waits indefinitely for the next message |
| `try_next()` | Non-blocking — returns `None` immediately if no message |
| `next_timeout(duration)` | Blocking with timeout — returns `io::Error` on timeout |

### Iterators

- **`iter()` / `messages()`** — Returns a blocking `Iter<'_>`
- **`try_iter()`** — Returns a non-blocking `TryIter<'_>`
- **`timeout_iter(duration)`** — Returns a `TimeoutIter<'_>` that stops after the deadline

### Handler Methods

- **`with_handler(F)`** — Spawns a background thread processing messages via a closure, returns a `Handler`
- **`with_process_handler(F)`** — Similar but intended for closures that also handle acknowledgment

## Usage Example

```rust
let client = nats::connect("demo.nats.io")?;
let context = nats::jetstream::new(client);
context.add_stream("events")?;

let subscription = context.subscribe("events")?;

// Blocking iteration
for message in subscription.iter() {
    println!("Received: {}", message);
}

// With timeout
if let Ok(msg) = subscription.next_timeout(Duration::from_secs(5)) {
    msg.ack()?;
}

// Background handler
subscription.with_handler(|message| {
    println!("Handled: {}", message);
    Ok(())
});
```

> **Note:** Flow control messages and idle heartbeats are transparently filtered before messages are delivered to the caller via the internal `preprocess()` method.
