Defines core JetStream types for stream messages and consumer configuration, providing serialization/deserialization support and conversion utilities between raw wire-format and structured Rust types.

## Key Components

| Item | Visibility | Description |
|------|-----------|-------------|
| `DateTime` | `pub` | Type alias for `time::OffsetDateTime` (UTC) |
| `RawStreamMessage` | `pub` | Wire-format stream message with base64-encoded data/headers |
| `StreamMessage` | `pub` | Decoded stream message with `Vec<u8>` payload and parsed `HeaderMap` |
| `ConsumerConfig` | `pub` | Full JetStream consumer configuration (push/pull, durable/ephemeral, ack policies, etc.) |
| `StreamMessage::try_from(RawStreamMessage)` | `pub` | Converts raw base64 message to decoded `StreamMessage` |
| `ConsumerConfig::validate_for` | `pub(crate)` | Validates config compatibility for a given consumer kind (e.g., pull) |
| `DeliverPolicy` / `AckPolicy` / `ReplayPolicy` | referenced | Enums controlling consumer delivery behavior |

## Usage Example

```rust
use std::convert::TryFrom;

// Decode a raw stream message received over JetStream
let raw: RawStreamMessage = serde_json::from_str(&json_payload)?;
let msg = StreamMessage::try_from(raw)?;

println!("Subject: {}", msg.subject);
println!("Sequence: {}", msg.sequence);
println!("Payload bytes: {}", msg.data.len());

// Build a durable pull consumer config
let config = ConsumerConfig {
    durable_name: Some("my-consumer".to_string()),
    ack_policy: AckPolicy::Explicit,
    max_deliver: 5,
    ack_wait: Duration::from_secs(30),
    filter_subject: "events.>".to_string(),
    ..Default::default()
};
```

> **Note:** `deliver_subject` must be `None` for pull consumers — `validate_for` enforces this and will return an error if a push-style subject is set on a pull subscription.
