Provides test-only fault injection utilities for stress-testing concurrent and I/O-related code paths by introducing random delays and simulated errors.

## Key Components

- **`inject_delay()`** — Induces random thread sleeps (up to 50ms) and/or `yield_now()` calls to expose concurrency interleavings. Uses a global + thread-local counter pair to skip delays when only a single thread is active. Compiled away entirely in non-test builds.
- **`inject_io_failure()`** — Returns a simulated `io::Error` with a ~1% probability (1-in-100 chance), enabling resilience testing of I/O error-handling paths.

## Usage Example

```rust
use crate::fault_injection::{inject_delay, inject_io_failure};

fn send_message(payload: &[u8]) -> io::Result<()> {
    // Shake out concurrency bugs under test
    inject_delay();

    // Simulate random I/O failures in test environments
    inject_io_failure()?;

    // Actual send logic here
    Ok(())
}
```

## Notes

- Both functions rely on [`fastrand`](https://crates.io/crates/fastrand) for lightweight, non-cryptographic randomness.
- `inject_delay()` is a no-op when only one thread is detected (global and local counters match), avoiding unnecessary slowdowns in single-threaded tests.
- Intended exclusively for test and development use; the compiler eliminates dead paths in release builds.
