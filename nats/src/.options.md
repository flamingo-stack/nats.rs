Configures NATS connection options including authentication, TLS, reconnection behavior, and event callbacks. Provides a builder-style API for constructing `Connection` instances.

## Key Components

- **`Options`** — Main configuration struct holding auth style, TLS settings, reconnection parameters, and lifecycle callbacks
- **`AuthStyle`** — Enum (referenced internally) supporting: no auth, token, username/password, credentials file, static credentials, JWT callback, and NKey
- **`backoff(reconnects: usize) -> Duration`** — Exponential backoff with jitter for reconnect delays (0ms → 4s max)
- **Constructor methods** — `new()`, `with_token()`, `with_user_pass()`, `with_credentials()`, `with_static_credentials()`, `with_jwt()`, `with_nkey()`
- **Builder methods** — `client_cert()`, and others (truncated) for TLS and connection tuning

## Usage Example

```rust
use nats::Options;

// Token auth
let nc = Options::with_token("t0k3n!")
    .connect("demo.nats.io")?;

// Username/password auth
let nc = Options::with_user_pass("derek", "s3cr3t!")
    .connect("demo.nats.io")?;

// Credentials file auth
let nc = Options::with_credentials("path/to/my.creds")
    .connect("connect.ngs.global")?;

// NKey auth with custom signer
let kp = nkeys::KeyPair::from_seed(seed).unwrap();
let nc = Options::with_nkey(nkey, move |nonce| kp.sign(nonce).unwrap())
    .connect("localhost")?;

// TLS with client certificate
let nc = Options::new()
    .client_cert("client-cert.pem", "client-key.pem")
    .connect("nats://localhost:4443")?;
```

## Defaults

| Setting | Default |
|---|---|
| `max_reconnects` | `Some(60)` |
| `reconnect_buffer_size` | `8 MB` |
| `retry_on_failed_connect` | `false` |
| `tls_required` | `false` |
| Reconnect delay | Exponential backoff |
