Provides two wrapper types — `SecureVec` and `SecureString` — that overwrite their heap-allocated contents with random bytes both on explicit request and automatically on `Drop`, preventing sensitive data from lingering in memory.

## Key Components

| Type | Visibility | Description |
|------|-----------|-------------|
| `SecureVec` | `pub(crate)` | A `Vec<u8>` wrapper that scrambles data on reallocation and drop |
| `SecureString` | `pub` (hidden) | A `String` wrapper that scrambles data on drop with a redacted `Debug` impl |

**Shared behavior:**
- `scramble()` — writes random bytes via `write_volatile` + `compiler_fence(SeqCst)` to prevent compiler/optimizer elision
- `Drop` — automatically calls `scramble()` when the value goes out of scope
- `Deref` — transparent access to the underlying slice/str
- `From<Vec<u8>>` / `From<String>` — cheap wrapping of existing allocations

`SecureVec::push` also scrambles the old buffer before reallocating, ensuring sensitive bytes are never left in abandoned heap memory during growth.

## Usage Example

```rust
use crate::secure_wipe::{SecureVec, SecureString};

// SecureVec — build up a sensitive byte payload
let mut secret_bytes = SecureVec::with_capacity(32);
for b in b"my-secret-token" {
    secret_bytes.push(*b);
}
// Data is accessible via Deref
assert_eq!(&*secret_bytes, b"my-secret-token");
// Scrambled automatically when `secret_bytes` is dropped

// SecureString — wrap a credential string
let password: SecureString = SecureString::from("hunter2".to_string());
// Debug output is redacted
println!("{:?}", password); // {"secure_data": "***********"}
// Scrambled automatically when `password` is dropped

// Manual scramble before passing ownership elsewhere
let mut creds = SecureString::from("api-key-xyz".to_string());
creds.scramble(); // wipe now, not just on drop
```

> **Implementation note:** Scrambling uses `write_volatile` (prevents dead-store elimination) paired with `compiler_fence(SeqCst)` (prevents reordering), mirroring the technique from the [`zeroize`](https://crates.io/crates/zeroize) crate but overwriting with random bytes rather than zeros.
