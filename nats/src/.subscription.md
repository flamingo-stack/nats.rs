Manages NATS subject subscriptions, providing blocking, non-blocking, and timeout-based message consumption patterns along with handler-based async processing.

## Key Components

- **`Subscription`** — Cloneable, `Arc`-backed struct representing an active NATS subscription. Automatically unsubscribes on drop via the inner `Drop` impl.
- **`Iter`** / **`TryIter`** / **`TimeoutIter`** — Blocking, non-blocking, and deadline-bounded message iterators.
- **`Handler`** — Returned by `with_handler`; runs a closure on a dedicated thread and does **not** auto-unsubscribe on drop.

### Key Methods

| Method | Behavior |
|---|---|
| `next()` | Blocks until a message arrives or subscription closes |
| `try_next()` | Returns immediately with `None` if no message is queued |
| `next_timeout(dur)` | Blocks up to `dur`, returns `io::Error` on timeout |
| `receiver()` | Exposes the raw `crossbeam_channel::Receiver` for use with `select!` |
| `with_handler(fn)` | Spawns a thread to process messages via a closure |
| `set_message_limits(n)` | Caps the internal queue; excess triggers a slow-consumer error |
| `dropped_messages()` | Returns count of messages dropped due to queue overflow |
| `unsubscribe()` / `close()` | Immediately cancels and drains the queue |
| `drain()` | Flushes pending messages before unsubscribing |

## Usage Example

```rust
use std::time::Duration;

let nc = nats::connect("demo.nats.io")?;

// Blocking iteration
let sub = nc.subscribe("events.>")?;
for msg in sub.iter() {
    println!("Received: {}", msg);
}

// Timeout-bounded receive
let sub = nc.subscribe("metrics")?;
match sub.next_timeout(Duration::from_secs(2)) {
    Ok(msg) => println!("Got: {:?}", msg),
    Err(e) => eprintln!("Timeout or closed: {e}"),
}

// Handler on a dedicated thread
nc.subscribe("alerts")?.with_handler(|msg| {
    println!("Alert: {}", msg);
    Ok(())
});

// Select across two subscriptions
let s1 = nc.subscribe("foo")?;
let s2 = nc.subscribe("bar")?;
crossbeam_channel::select! {
    recv(s1.receiver()) -> msg => println!("foo: {:?}", msg),
    recv(s2.receiver()) -> msg => println!("bar: {:?}", msg),
}
```
