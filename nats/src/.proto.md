Handles NATS protocol encoding and decoding for both server-to-client and client-to-server protocol operations over a buffered I/O stream.

## Key Components

### `ServerOp` Enum
Represents operations received from the NATS server:
- `Info(ServerInfo)` — Initial server info payload
- `Msg` — Standard message with subject, sid, optional reply-to, and payload
- `Hmsg` — Message with HTTP-style headers plus payload
- `Ping` / `Pong` — Keepalive operations
- `Err(String)` — Server-side error
- `Unknown(String)` — Unrecognized protocol line

### `ClientOp<'a>` Enum
Represents operations sent by the client (zero-copy, borrows data via lifetime `'a`):
- `Connect(&ConnectInfo)` — Initial connection handshake
- `Pub` — Publish a message
- `Hpub` — Publish with headers
- `Sub` — Subscribe to a subject with optional queue group
- `Unsub` — Unsubscribe, optionally with max message count
- `Ping` / `Pong` — Keepalive responses

### `decode(stream: impl BufRead) -> io::Result<Option<ServerOp>>`
Reads and parses a single server operation from a buffered reader. Returns `None` on connection close.

### `encode(stream: impl Write, op: ClientOp) -> io::Result<()>`
Serializes a single client operation and writes it to the given writer.

### `read_line<R: BufRead>(r, buf)` *(private)*
Fixed-buffer line reader using `memchr` for efficient newline scanning, avoiding heap allocation.

## Usage Example

```rust
use std::io::BufReader;

// Decode a server operation from a TCP stream
let buf_reader = BufReader::new(tcp_stream);
match proto::decode(buf_reader)? {
    Some(ServerOp::Msg { subject, payload, .. }) => {
        println!("Received on {}: {:?}", subject, payload);
    }
    Some(ServerOp::Ping) => {
        // Respond with PONG
        proto::encode(&mut writer, ClientOp::Pong)?;
    }
    None => println!("Connection closed"),
    _ => {}
}

// Encode a publish operation
proto::encode(&mut writer, ClientOp::Pub {
    subject: "foo.bar",
    reply_to: None,
    payload: b"hello world",
})?;
```
