Implements the NATS JetStream Key-Value Store API, providing bucket management and CRUD operations for persistent key-value data backed by JetStream streams.

## Key Components

- **`Config`** – Bucket configuration struct (name, history depth, TTL, storage type, replication)
- **`Store`** – Primary handle for interacting with a KV bucket; exposes `get`, `put`, `delete`, `purge`, `entry`, `keys`, `watch`, and `status` operations
- **`Entry`** – A retrieved key-value entry including value bytes, revision sequence, timestamp, and `Operation` kind
- **`Operation`** – Enum describing the entry type: `Put`, `Delete`, or `Purge`
- **`BucketStatus`** – Wraps `StreamInfo` to expose bucket-level metadata
- **`JetStream` extension methods** – `key_value()`, `create_key_value()`, `delete_key_value()` for bucket lifecycle management

Bucket names are validated against `[a-zA-Z0-9_-]+`; keys against `[-/_=\.a-zA-Z0-9]+`. History depth is capped at 64 entries per key. Requires NATS server ≥ 2.6.2.

## Usage Example

```rust
use nats::kv::Config;

fn main() -> std::io::Result<()> {
    let client = nats::connect("demo.nats.io")?;
    let context = nats::jetstream::new(client);

    // Create a bucket with 5 historical revisions per key
    let bucket = context.create_key_value(&Config {
        bucket: "my_store".to_string(),
        history: 5,
        ..Default::default()
    })?;

    // Write a value
    bucket.put("config.timeout", b"30s")?;

    // Read latest entry
    if let Some(entry) = bucket.entry("config.timeout")? {
        println!("revision={} value={:?} op={:?}",
            entry.revision,
            String::from_utf8_lossy(&entry.value),
            entry.operation,
        );
    }

    // Delete a key
    bucket.delete("config.timeout")?;

    // Clean up the bucket
    context.delete_key_value("my_store")?;
    Ok(())
}
```
