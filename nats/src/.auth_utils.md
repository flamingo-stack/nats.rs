Utility module for NATS authentication, providing helpers to load and parse credentials files, sign nonces with NKeys, and load TLS client certificates and keys from PEM files.

## Key Components

| Function | Description |
|---|---|
| `load_creds(path)` | Reads a `.creds` file and returns a parsed `(JWT, KeyPair)` tuple |
| `jwt_kp(contents)` | Parses raw credentials string into a `(SecureString JWT, KeyPair)` |
| `sign_nonce(nonce, key_pair)` | Signs a server nonce with an NKey `KeyPair`, returning a Base64URL-encoded signature |
| `load_certs(path)` | Loads DER-encoded TLS client certificates from a PEM file |
| `load_key(path)` | Loads a private TLS key from a PEM file |
| `USER_CONFIG_RE` | Lazily compiled regex for parsing PEM-style blocks in NATS credentials files |

## Usage Example

```rust
use std::path::Path;
use auth_utils::{load_creds, sign_nonce, load_certs, load_key};

// Load a NATS .creds file and sign a server-provided nonce
let (jwt, key_pair) = load_creds(Path::new("~/.nkeys/creds/my-account.creds"))?;
let signed = sign_nonce(b"server-nonce-bytes", &key_pair)?;

// Load TLS client certificate and private key from PEM files
let certs = load_certs(Path::new("/path/to/client.pem"))?;
let key   = load_key(Path::new("/path/to/client.pem"))?;
```

## Credentials File Format

The parser expects the standard NATS `.creds` layout with two PEM-style blocks — the user JWT first, followed by the NKey seed:

```text
-----BEGIN NATS USER JWT-----
eyJ0eXAiOiJqd3QiLCJhbGciOiJlZDI1NTE5...
------END NATS USER JWT------

-----BEGIN USER NKEY SEED-----
SUAIO3FHUX5PNV2LQIIP7TZ3N4L7TX3W53MQGEIVYFIGA635OZCKEYHFLM
------END USER NKEY SEED------
```
