Defines the `ConnectInfo` struct and `Protocol` enum used to construct the NATS `CONNECT` protocol message sent during client handshake.

## Key Components

- **`ConnectInfo`** — Holds all fields required to build a NATS `CONNECT` message, including authentication credentials (JWT, nkey, password, token), TLS requirements, protocol version, and capability flags (`headers`, `no_responders`, `echo`).
- **`Protocol`** — Enum representing the NATS protocol version: `Original` (0) for the baseline protocol, or `Dynamic` (1) for cluster topology reconfiguration support.
- **`ConnectInfo::dump()`** — Serializes the struct into a JSON string suitable for transmission as the `CONNECT` message body; optional fields are omitted if `None`.

## Usage Example

```rust
use crate::connect::{ConnectInfo, Protocol};

let info = ConnectInfo {
    verbose: false,
    pedantic: false,
    user_jwt: None,
    nkey: None,
    signature: None,
    name: Some("my-client".into()),
    echo: true,
    lang: "rust".to_string(),
    version: "0.1.0".to_string(),
    protocol: Protocol::Dynamic,
    tls_required: false,
    user: Some("alice".into()),
    pass: Some("secret".into()),
    auth_token: None,
    headers: true,
    no_responders: true,
};

// Serialize to JSON for the CONNECT wire message
if let Some(json) = info.dump() {
    println!("CONNECT {}", json);
}
```

## Notes

- All sensitive fields (`user_jwt`, `nkey`, `signature`, `pass`, `auth_token`) use `SecureString` to reduce accidental exposure in logs or debug output.
- `dump()` returns `None` only if JSON insertion fails internally, which is not expected under normal use.
